- 所有 NPM 子包共享根目录的 `package-lock.json`，并通过 `lib.nix` 中的 `mkNpmDevShellHook` 统一检测变更并触发 `npm ci`。
- Python 虚拟环境构建优先使用 `sourcePreference = "wheel"`，并在 `python.nix` 中针对特定平台（如 aarch64-darwin）提供预编译包的 `mkPrebuiltOverride`。
- NixOS 模块激活脚本通过 `configMergeScript.nix` 将声明式 `settings` 深度合并到现有的 `config.yaml` 中，保留用户手动添加的配置项。
- 派生包（Derivation）通过 `passthru` 暴露内部组件（如 `hermesVenv`, `hermesNpmLib`），以便在 `devShell.nix` 和其他子模块中复用。
