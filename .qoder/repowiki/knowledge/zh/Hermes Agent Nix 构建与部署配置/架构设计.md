- **核心入口**：`hermes-agent.nix` 作为主包定义，通过 `callPackage` 组合 Python (`python.nix`) 和前端 (`tui.nix`, `web.nix`) 子模块。
- **依赖管理**：利用 `uv2nix` 和 `pyproject-nix` 从 `pyproject.toml` 生成确定性 Python 虚拟环境；通过 `lib.nix` 中的 `mkNpmPassthru` 统一管理 NPM 工作区的 `package-lock.json` 哈希。
- **部署抽象**：`nixosModules.nix` 定义了 `services.hermes-agent`，支持原生 systemd 服务和 OCI 容器（Docker/Podman）两种运行模式，并处理配置合并与权限初始化。
- **扩展机制**：通过 `overlays.nix` 暴露 `pkgs.hermes-agent`，支持通过 `override` 注入额外的 Python 包或依赖组（如 `messaging`, `full`）。
