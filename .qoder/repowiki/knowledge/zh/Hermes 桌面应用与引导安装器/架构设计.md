- **多运行时架构**：`desktop/` 采用 Electron (Node.js + Chromium) 构建功能完备的主客户端，支持原生终端 (node-pty) 和复杂窗口管理；`bootstrap-installer/` 采用 Tauri (Rust + Webview) 构建轻量级、高安全性的初始环境配置与安装向导。
- **通信层抽象**：通过 `shared/` 模块定义 `JsonRpcGatewayClient`，统一封装基于 WebSocket 的 JSON-RPC 协议，实现渲染层与 Python 后端的解耦通信。
- **后端生命周期管理**：Electron 主进程 (`main.cjs`) 负责探测、启动及监控 Hermes Python 后端，处理多 Profile 切换、端口分配及崩溃恢复；Tauri 后端 (`src-tauri/`) 负责执行 PowerShell/Bash 脚本以完成依赖安装和环境初始化。
- **状态驱动 UI**：前端采用 React + Vite 技术栈，利用 `nanostores` 进行全局状态管理（如会话、网关连接、布局），并通过 `react-router-dom` 实现复杂的覆盖层路由（如设置、模型选择）。
