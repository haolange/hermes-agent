- **分层架构**：采用 `packages/hermes-ink`（底层渲染引擎）与 `src/`（业务逻辑层）分离的设计。`hermes-ink` 封装了 Yoga 布局引擎、ANSI 解析及 React  reconciler，为上层提供声明式 UI 原语。
- **状态管理**：使用 `nanostores` 实现全局状态（如 `$uiState`, `$overlayState`）的细粒度响应式更新，结合 React Hooks 管理组件局部状态。
- **通信机制**：通过 `GatewayClient` 与后端建立 RPC 通信，利用事件驱动模型（`gateway.on('event')`）处理流式数据、会话生命周期及系统通知。
- **渲染优化**：引入虚拟滚动（`useVirtualHistory`）和高度缓存机制，确保长会话下的渲染性能；支持 AlternateScreen 模式以隔离终端环境。
