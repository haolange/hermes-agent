- **模块化文档结构**：按功能域划分为 `kanban`（多网关并发与调度）、`middleware`（请求/执行拦截契约）、`observability`（只读遥测钩子）和 `security`（Docker 网络隔离）。
- **核心契约定义**：在 `middleware/README.md` 和 `observability/README.md` 中明确了插件扩展的 API 接口，区分了行为改变（Middleware）与状态报告（Observer Hooks）的边界。
- **部署与安全规范**：`kanban/multi-gateway.md` 定义了单调度器姿态以规避 SQLite 竞争，`security/network-egress-isolation.md` 提供了基于 Docker 双网络模型的防注入架构方案。
