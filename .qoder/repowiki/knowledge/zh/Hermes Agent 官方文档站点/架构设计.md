- **框架核心**：采用 `@docusaurus/preset-classic` 预设，配置 `routeBasePath: '/'` 将文档置于站点根路径，并启用 `@docusaurus/theme-mermaid` 支持流程图渲染。
- **内容架构**：通过 `sidebars.ts` 定义多层级导航结构，涵盖入门指南、用户手册（含 20+ 消息平台适配）、功能特性、开发者指南及参考手册。
- **自动化构建**：利用 `scripts/prebuild.mjs` 作为入口，在构建前自动触发 Python 脚本（`generate-skill-docs.py` 和 `generate-llms-txt.py`），从源码同步技能定义并生成机器可读的 `llms.txt` 索引。
- **国际化支持**：在 `docusaurus.config.ts` 中配置 `en` 与 `zh-Hans` 双语言环境，并通过 `@easyops-cn/docusaurus-search-local` 实现跨语言全文检索。
