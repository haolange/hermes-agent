- **插件化适配器注册**：通过 `platform_registry.py` 实现内置与第三方插件适配器的统一发现与实例化，解耦核心逻辑与具体平台实现。
- **流式事件分发架构**：采用 `GatewayEventDispatcher` 将 Agent 产生的结构化流式事件（如文本块、工具调用）路由至 `GatewayStreamConsumer`，由消费者根据平台特性（如 Telegram 的 Draft API 或通用 Edit 模式）进行异步渲染与投递。
- **统一交付路由**：`DeliveryRouter` 负责解析交付目标（如 Home Channel、Origin 或特定 Chat ID），并处理跨平台的媒体缓存、内容截断及静默过滤等通用逻辑。
- **生命周期钩子扩展**：基于 `hooks.py` 提供网关启动、会话起止及 Agent 执行等关键节点的异步事件钩子，支持用户通过 `~/.hermes/hooks/` 目录动态注入自定义逻辑。
