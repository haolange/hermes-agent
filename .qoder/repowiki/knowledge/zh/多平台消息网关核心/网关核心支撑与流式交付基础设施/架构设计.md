- **流式交付层**：采用生产者-消费者模型，`stream_consumer.py` 通过线程安全队列桥接同步 Agent 回调与异步平台编辑操作，支持原生草稿（Draft）与渐进式编辑（Edit）两种传输模式。
- **事件分发层**：`stream_dispatch.py` 与 `stream_events.py` 定义了结构化的流式事件契约（如 `MessageChunk`, `ToolCallChunk`），实现 Agent 逻辑与平台渲染的解耦。
- **状态与身份层**：`channel_directory.py` 维护跨平台的通道缓存；`mirror.py` 负责跨会话的消息镜像同步；`whatsapp_identity.py` 处理 WhatsApp 复杂的 LID/Phone 身份归一化。
- **配置与访问控制**：`display_config.py` 实现基于平台能力的分层显示配置解析；`slash_access.py` 提供细粒度的斜杠命令权限控制。
- **运维监控层**：`memory_monitor.py` 和 `shutdown_forensics.py` 分别负责周期性内存快照记录与停机信号的法医级上下文捕获，保障长期运行的可观测性。
