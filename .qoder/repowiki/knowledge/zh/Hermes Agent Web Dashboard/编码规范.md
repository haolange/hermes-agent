- 所有 API 请求均通过 `lib/api.ts` 中的 `fetchJSON` 或 `authedFetch` 发起，自动处理 `X-Hermes-Session-Token` 头部注入及 Cookie 凭证携带。
- 国际化文本统一通过 `useI18n()` Hook 获取 `t` 对象访问，支持 16 种语言并在 `localStorage` 中持久化用户偏好。
- 插件系统采用“主机暴露 SDK + 插件注册组件”的模式，插件不直接打包 React 依赖，而是通过 `window.__HERMES_PLUGINS__` 接口与宿主通信。
- 路由导航项（NavItem）采用声明式数组定义，支持通过插件 Manifest 中的 `position` 字段（如 `after:skills`）动态插入侧边栏。
