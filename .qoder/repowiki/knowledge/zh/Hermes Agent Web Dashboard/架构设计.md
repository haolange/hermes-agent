- **技术栈与构建**：采用 React 19 + TypeScript + Vite 7 架构，使用 Tailwind CSS v4 进行样式管理，并通过 `@nous-research/ui` 共享设计语言组件。
- **路由与布局**：以 `App.tsx` 为核心布局容器，集成 `react-router-dom` 实现多页面导航。侧边栏支持响应式折叠，并根据 `dashboard.show_token_analytics` 配置动态过滤导航项。
- **插件化架构**：通过 `exposePluginSDK` 在 `window` 对象上暴露 React 核心、API 客户端及 UI 组件，允许外部插件通过 `register` 方法动态注入路由页面或 UI 插槽（Slots）。
- **状态与上下文**：利用 React Context 管理全局主题（`ThemeProvider`）、国际化（`I18nProvider`）及系统动作（`SystemActionsProvider`），实现跨组件的状态同步。
- **通信层**：封装 `lib/api.ts` 处理 RESTful 请求与 WebSocket 连接，内置针对 OAuth 门禁模式（Gated Mode）与本地回环模式的自动鉴权逻辑（Session Token 或 Ticket 交换）。
