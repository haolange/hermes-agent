测试套件按被测子系统镜像目录结构组织：`tests/` 下每个顶级目录（`agent/`、`gateway/`、`cli/`、`hermes_cli/`、`tools/`、`run_agent/`、`cron/`、`plugins/`、`skills/`、`docker/`、`e2e/`、`integration/`、`stress/`、`ci/`、`conformance/`、`computer_use/`、`dashboard/`、`fakes/`、`fixtures/`、`honcho_plugin/`、`install/`、`manual/`、`monitoring/`、`openviking_plugin/`、`providers/`、`scripts/`、`secret_sources/`、`state/`、`tui_gateway/`、`verify/`、`website/` 等）对应源码中同名模块；`tests-js/` 存放 JS 侧测试。入口由 `tests/conftest.py` 统一提供跨文件夹具：在导入任何测试模块前强制设置 `HERMES_HOME` 为临时目录、清理所有以 `_API_KEY/_TOKEN/_SECRET/_PASSWORD` 结尾的凭据环境变量、固定 `TZ=UTC LANG=C.UTF-8 PYTHONHASHSEED=0`，并通过 `scripts/run_tests_parallel.py` 以“每测试文件一个独立 Python 进程”的方式运行，实现进程级隔离。JS 测试通过 `tests-js/vitest.config.ts` 使用 Vitest 4.1 在 Node 环境执行，脚本定义在 `package.json` 中。各子目录可自带 `conftest.py`（如 `tests/acp/conftest.py`、`tests/cli/conftest.py`）叠加本地夹具，形成“根 conftest 全局隔离 + 子目录局部夹具”的分层夹具体系。
