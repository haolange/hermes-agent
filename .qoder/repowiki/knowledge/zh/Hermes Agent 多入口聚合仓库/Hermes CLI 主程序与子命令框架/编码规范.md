- 每个子命令文件统一提供 `build_<cmd>_parser` 与 `cmd_<cmd>` 两个符号，由 `main.py` 集中 import 并挂载到 argparse subparsers。
- 跨子命令复用的顶层 flag（如 `--model`、`--provider`、`--resume`、`--tui`、`--cli`、`--safe-mode` 等）通过 `_parser._inherited_flag` 标记 `inherit_on_relaunch=True`，以便 relaunch 时原样传递。
- Dashboard 鉴权通过继承 `DashboardAuthProvider` 并在 `registry.register_provider` 中注册的方式扩展，而非硬编码分支。
- 可观测性钩子通过 `observability.observe_lifecycle(hook_name, **kwargs)` 统一派发，调用方无需感知具体消费者。
- HTTP 代理通过 `adapters.base.UpstreamAdapter` 抽象定义 `get_credential()` / `allowed_paths` / `display_name` 接口，新增上游只需实现该适配器。
- slash 命令全部声明在 `commands.COMMAND_REGISTRY` 的 `CommandDef` 数据类列表中，并通过 `cli_only`、`gateway_only`、`busy_policy`、`execute` 等字段驱动多端（CLI/Gateway/Telegram/Discord）自动推导行为。
