- 每个技能目录必须包含 `SKILL.md`，并使用 YAML front matter 声明 name、description、version、author、license、platforms 及 metadata.hermes 下的 tags/category/related_skills。
- 可执行逻辑统一放在 `scripts/` 目录下，并通过相对路径 `~/.hermes/skills/<domain>/<skill>/scripts/<script>` 引用，避免硬编码绝对路径。
- 参考知识集中存放在 `references/` 子目录，按主题拆分为多个 `.md` 文件，由 SKILL.md 在正文中显式列出并建议按需加载。
- 对外部工具的调用通过 shell 命令或 Python 脚本封装，SKILL.md 内提供完整的检测流程（command -v / --version）和降级策略（如 gh CLI 不可用则回退到 git + curl）。
- 涉及多平台时，front matter 的 `platforms` 字段显式列出支持系统，并在脚本中以 `if command -v ...` 或 `uname` 判断后分支执行。
- 可选技能与默认技能保持相同目录结构，通过是否位于 `optional-skills/` 来区分启用状态，便于按需分发。
