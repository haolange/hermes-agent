模块采用扁平目录 + 元数据驱动的插件式架构：
- 顶层 `skills/` 为默认启用的技能集，`optional-skills/` 为可选技能集，两者结构完全对称，均按领域（apple、creative、github、mlops、productivity、research、security 等）分目录组织。
- 每个子目录是一个独立技能，核心入口是 `SKILL.md`，使用 YAML front matter 声明 `name/description/version/author/license/platforms/metadata.hermes.tags/category/related_skills` 等元数据，供上层 skill 索引器解析。
- 技能内部通过固定约定组织资源：`scripts/` 存放可执行脚本（Python/shell/JS），`references/` 存放参考文档，`templates/` 存放模板文件，`workflows/` 存放工作流定义（如 ComfyUI JSON），`tests/` 存放单元测试。
- `skills/index-cache/` 包含由外部索引生成的缓存文件（`anthropics_skills_skills_.json`、`openai_skills_skills_.json`、`lobehub_index.json`），用于快速发现可用技能及其 trust_level/source/path。
- 依赖方向单向：技能之间通过 `metadata.hermes.related_skills` 建立弱引用，不直接 import；跨平台能力通过 `platforms` 字段声明，由宿主环境决定加载。
- 复杂技能（如 comfyui、evm、docx/pptx/xlsx）将自身封装为“文档+脚本”单元，通过 shell/python 调用外部工具（comfy-cli、gh CLI、Office Python 库、RPC 端点），SKILL.md 仅承担编排与说明职责。
