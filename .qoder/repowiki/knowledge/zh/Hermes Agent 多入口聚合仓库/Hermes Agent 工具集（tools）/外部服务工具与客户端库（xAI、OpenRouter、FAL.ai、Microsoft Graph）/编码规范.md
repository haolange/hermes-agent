- 对外部 API 调用统一采用 try/except 捕获异常并以 JSON 字符串返回 `{success, provider, tool, error, error_type}` 的错误响应，而非向上抛出原始异常。
- 凭据解析遵循「OAuth/managed pool 优先，环境变量回退」的分层策略，并通过 `resolve_xai_http_credentials`、`GraphCredentials.from_env` 等工厂方法集中处理，避免在工具函数内散落 env 读取逻辑。
- HTTP 客户端调用均内置重试循环：对 5xx / 429 / 网络超时执行指数退避，并在 401 时触发 token 刷新或凭据重新选择。
- 可选配置通过 `hermes_cli.config.load_config()` 的局部 section 读取并提供默认值，所有转换函数（如 `_coerce_bool`、`_coerce_expires_after`）对非法输入做宽容降级而非直接抛错。
- 第三方 SDK 导入一律延迟到首次使用时进行（`import_fal_client`、`get_async_client`），并通过模块级全局变量缓存实例，以缩短 CLI 冷启动时间。
- Microsoft Graph 相关错误统一抽象为继承自 `MicrosoftGraphAuthError` / `MicrosoftGraphClientError` 的自定义异常层次，携带 status_code、method、url 等结构化字段。
