本模块按外部服务划分成独立子文件，每个文件聚焦单一提供方：
- `x_search_tool.py` 通过 `tools.registry.register` 将 `x_search` 工具暴露给上层 agent，使用 `requests` 直接调用 xAI `/responses` 端点，并通过 `tools.xai_http.resolve_xai_http_credentials` 优先走 SuperGrok OAuth 再回退到 `XAI_API_KEY`；同时定义 `X_SEARCH_SCHEMA` 参数 schema 和 `check_x_search_requirements` 可用性探针。
- `xai_http.py` 是 xAI 直连 HTTP 的共享层，提供凭据解析（OAuth pool → `XAI_API_KEY`）、User-Agent 构造、存储 TTL 配置读取与一次性提示标记等通用能力，被 `x_search_tool` 及其他 xAI 工具复用。
- `openrouter_client.py` 仅维护一个惰性初始化的全局 AsyncOpenAI 客户端，委托给 `agent.auxiliary_client.resolve_provider_client("openrouter")`，并封装 `OPENROUTER_API_KEY` 的存在性检查以适配 profile secret scope。
- `fal_common.py` 提供 FAL.ai SDK 的懒加载导入（通过 `tools.lazy_deps.ensure` 避免冷启动开销）以及 `_ManagedFalSyncClient` 包装器，用于驱动 Nous 托管的 fal-queue 网关；状态缓存刻意留在调用方模块以便测试 monkeypatch。
- `microsoft_graph_auth.py` 实现 Microsoft Graph app-only 认证：`GraphCredentials` dataclass 从 `MSGRAPH_*` 环境变量解析，`MicrosoftGraphTokenProvider` 用 httpx 发起 `client_credentials` 令牌请求并带异步锁与过期时间戳缓存。
- `microsoft_graph_client.py` 基于 `httpx.AsyncClient` 构建带重试、分页（`@odata.nextLink`）、401 自动刷新 token、指数退避与流式下载的通用 Graph 客户端，依赖 `agent.retry_utils.parse_retry_after_seconds` 处理 Retry-After。
依赖方向单向向外：工具层 → 共享客户端 → 第三方 SDK/httpx/requests；模块内部各文件之间无循环依赖，仅 `microsoft_graph_client` 依赖 `microsoft_graph_auth`。
