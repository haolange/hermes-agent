本模块是 tools/ 下的纯 Python 支撑层，不依赖上层 agent/gateway，被各具体 tool_* 文件以 import 方式消费。内部按职责拆分为若干独立子能力：
- 工具注册与调度：`registry.py` 通过 `ToolRegistry` 单例收集每个工具模块在导入时调用的 `registry.register()`，维护 schema/handler/check_fn/toolset；`discover_builtin_tools` 用 AST 扫描 + 磁盘缓存自动发现并导入所有自注册工具；`dispatch` 统一执行同步/异步 handler 并以 `tool_error`/`tool_result` 规范化返回值。
- 结果大小控制三层防线：`budget_config.BudgetConfig`（含 per-tool 阈值、per-turn 预算、按模型 context window 缩放）→ `tool_result_storage.maybe_persist_tool_result`（超阈值写入 sandbox `/tmp/hermes-results`，返回 `<persisted-output>` 包裹的预览）→ `enforce_turn_budget`（整轮聚合超限后按大小回退到磁盘）；`tool_output_limits` 集中读取 `config.yaml.tool_output` 中的 max_bytes/max_lines/max_line_length 覆盖终端/文件输出截断。
- 文件系统快照：`checkpoint_manager.CheckpointManager` 基于单个共享 bare git store（`~/.hermes/checkpoints/store`），通过 `GIT_DIR/GIT_WORK_TREE/GIT_INDEX_FILE` 隔离用户项目，实现每 turn 一次的去重快照、diff、restore、session_diff 及自动 prune。
- 后台进程管理：`process_registry.ProcessRegistry` 维护 `ProcessSession`（PID、输出缓冲、watch patterns、completion queue），支持 spawn_local/spawn_via_env、systemd cgroup 隔离、psutil tree-kill、crash recovery（`processes.json`）以及全局 watch 防抖/熔断。
- 并发与线程安全：`daemon_pool.DaemonThreadPoolExecutor` 继承 stdlib `ThreadPoolExecutor` 并将 worker 设为 daemon，避免挂起线程阻塞解释器退出；`thread_context.propagate_context_to_thread` 用 `contextvars.copy_context` 把 approval/sudo 回调复制到工作线程；`interrupt.set_interrupt/is_interrupted` 提供 per-thread 中断位；`registry.ToolRegistry` 用 `RLock` + generation counter 保护并发注册/MCP 动态刷新。
- 环境与凭据：`env_passthrough` 维护 session-scoped 白名单（`ContextVar`），拒绝 Hermes 提供商密钥（GHSA-rhgp-jrhgp-jrhgp-j443-p4rf 修复），并通过 `agent.secret_scope` 在多路复用 profile 下解析值；`credential_files`、`env_probe`、`lazy_deps` 提供凭据文件加载、环境变量探测、惰性依赖导入。
- 辅助能力：`blueprints` 将 SKILL.md frontmatter 中的 `metadata.hermes.blueprint` 解析为 `BlueprintSpec` 并桥接到 cron job；`fuzzy_match` 提供 9 策略文本替换链（exact → line_trimmed → whitespace_normalized → indentation_flexible → escape_normalized → trimmed_boundary → unicode_normalized → block_anchor → context_aware）；`approval.py`、`slash_confirm.py`、`hook_output_spill.py`、`ansi_strip.py`、`debug_helpers.py` 分别处理审批流、斜杠确认、钩子输出溢出、ANSI 清理和调试打印。
依赖方向单向向外：本模块可被 tools/*、agent、gateway 导入，但自身仅依赖 stdlib、hermes_cli、hermes_constants、utils 等底层包，不被同层工具反向依赖。
