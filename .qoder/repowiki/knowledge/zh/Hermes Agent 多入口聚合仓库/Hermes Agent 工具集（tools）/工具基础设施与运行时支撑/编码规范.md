- 工具通过模块级调用 `registry.register(name, toolset, schema, handler, check_fn=...)` 完成自注册，由 `discover_builtin_tools` 自动发现并导入，避免显式清单。
- 对外部状态探测（check_fn、systemd 可用性、git 存在性）采用带 TTL 的进程内缓存，并在失败窗口内服务上次成功的 True 以吸收瞬态抖动。
- 大输出统一走 `maybe_persist_tool_result` / `enforce_turn_budget` 的两层持久化：先写 sandbox 再返回 `<persisted-output>` 包裹的预览，未命中则 inline 截断。
- 配置读取一律通过 `hermes_cli.config.load_config`/`cfg_get` 并捕获异常回退到内置默认值，保证工具永不因配置缺失崩溃。
- 线程间共享状态使用 `threading.Lock`/`RLock` 保护可变字典，并通过 `_snapshot_state` + monotonically increasing `_generation` 向外部暴露稳定快照。
- 敏感操作（如 env passthrough 注册、插件 override）对 Hermes 提供商密钥进行硬阻断，fail-closed 且记录警告日志。
