`checkpoint_manager` 首次使用时会在 `~/.hermes/checkpoints/store` 初始化 bare git repo 并迁移 v1 遗留仓库到 `legacy-<timestamp>/`；`process_registry` 在 gateway 模式下会探测 `systemd-run --user --scope` 可用性并缓存结果；`registry.discover_builtin_tools` 将 AST 扫描结果缓存到 `{hermes_home}/cache/tool_discovery_cache.json`，键为 `(mtime_ns, size)`。
