本模块以 tools/registry.py 中的 ToolRegistry 单例为核心编排点：每个工具文件在模块顶层调用 registry.register(name, toolset, schema, handler, check_fn, ...) 完成自注册；discover_builtin_tools 通过 AST 扫描 *.py 识别含 register 调用的模块并动态 import 触发注册，从而将 browser_tools、file_code_tools、mcp_tools、tts_audio_tools、skills_hub、delegation_tools、security_tools、kanban_project_tools、communication_tools、web_search_tools、media_generation_tools、terminal_desktop_tools、cron_and_voice_tools 等子模块统一接入。运行时通过 get_definitions 过滤 check_fn（带 30s TTL + 瞬态失败宽容窗口）、dispatch 执行 handler（同步/异步桥接、结果规范化为字符串或 _multimodal envelope），并通过 toolset/toolset_alias 机制实现分组暴露与覆盖策略（override=True + 插件命名空间授权）。各子模块仅依赖 registry 的注册契约与 security_tools 提供的 path/url/command 守卫，不直接互相调用，从而实现领域隔离与热插拔。
