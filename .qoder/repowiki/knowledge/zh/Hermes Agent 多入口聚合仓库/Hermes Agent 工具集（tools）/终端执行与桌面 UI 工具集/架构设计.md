模块由两类子能力组成：
- 终端执行核心 `terminal_tool.py`：实现多后端（local/docker/modal/vercel_sandbox/singularity/daytona/ssh）的命令调度，包含 sudo 密码缓存与交互式提示、危险命令审批（委托 `tools.approval`）、工作目录白名单校验、后台复合命令重写（`A && B &` → `{ B & }`）、磁盘用量告警缓存等；通过 `tools.interrupt.is_interrupted` 支持用户中断。
- 输出模式提示 `terminal_hints.py`：对非零退出码的输出做前 4000 字符扫描，按生产频率顺序匹配 gh 字段不兼容、command not found、ModuleNotFoundError、git 冲突、权限拒绝等模式，返回单条可操作恢复建议。
- 桌面 UI 桥接 `desktop_ui.py`：维护全局 `_emit` 回调，由桌面 tui_gateway 安装，将事件路由到当前 `HERMES_UI_SESSION_ID` 对应的窗口；`available()` 用于运行时检测是否在桌面环境。
- 具体桌面工具（`focus_pane_tool.py`、`open_preview_tool.py`、`read_preview_tool.py`、`read_terminal_tool.py`、`close_terminal_tool.py`）均为薄包装：定义 JSON Schema + handler，注册到 `tools.registry` 的 `desktop_ui` toolset，通过 `desktop_ui.emit` 或进程注册表向渲染器发出事件（如 `pane.reveal`、`preview.open`、`terminal.read.request`），不在 CLI/messaging/cron 环境中暴露。
依赖方向单向：桌面工具 → `desktop_ui` → 渲染器；终端执行 → `tools.approval` / `tools.process_registry` / `tools.environments.*`，不反向依赖桌面层。
