- 每个桌面工具文件独立定义 `*_SCHEMA` 常量并通过 `registry.register(name=..., toolset="desktop_ui", schema=..., handler=lambda args, **kw: ..., emoji=...)` 完成注册。
- 桌面相关工具统一通过 `desktop_ui.emit(event, payload)` 发送事件，并在返回前用 `tool_error(...)` 包装失败路径，未启用时返回“仅在 Hermes 桌面应用中可用”的错误消息。
- 终端工具中的敏感输出在序列化前调用 `agent.redact.redact_sensitive_text(..., force=True)` 进行脱敏。
- 对外部命令输出进行失败归因时，采用按频率排序的纯函数列表（`_OUTPUT_HINTS`），首个匹配即返回，保证无 I/O、可单元测试。
- 交互式输入（sudo 密码、危险命令审批）通过线程局部存储 `_callback_tls` 注册回调，避免并发 ACP 会话互相覆盖。
- 所有模块级数值配置使用 `_safe_parse_import_env` 解析环境变量，解析失败时记录警告并回退默认值，确保模块导入阶段不会因脏环境变量崩溃。
