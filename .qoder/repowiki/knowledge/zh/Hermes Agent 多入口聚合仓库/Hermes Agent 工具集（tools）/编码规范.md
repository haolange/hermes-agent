- 每个工具文件在模块顶层调用 registry.register(name, toolset, schema, handler, check_fn=...) 完成自注册，禁止在函数内部注册。
- handler 返回 JSON 字符串，错误使用 tool_error(...)、成功使用 tool_result(...)，避免直接拼接 json.dumps。
- 对外部环境探测（Docker/Playwright/Modal/网络）通过 check_fn 声明并在 registry 中以 30s TTL + 瞬态失败宽容窗口缓存。
- 工具按领域划分 toolset（如 terminal、browser、mcp-*、communication），跨 toolset 同名覆盖需显式 override=True 并经插件授权策略。
- 对模型可见的错误体统一经 _bound_error_text 截断，防止异常堆栈撑大上下文。
