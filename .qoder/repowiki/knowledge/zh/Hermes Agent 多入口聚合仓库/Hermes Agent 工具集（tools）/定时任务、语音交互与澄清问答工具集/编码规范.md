- 外部重型依赖（sounddevice、numpy、cron.*、gateway.*、hermes_cli.config）一律在函数体内延迟 import，避免在无头/缺失依赖环境中模块加载失败。
- 面向用户的工具通过 `tools.registry.register(name, toolset, schema, handler, check_fn, emoji)` 统一注册，handler 从 args 中取值后调用具体实现函数。
- 安全边界校验集中为独立 `_validate_*` / `_scan_*` 函数，返回错误字符串或 None，由调用方统一判断并格式化为用户可读的错误消息。
- 跨线程/跨进程状态使用模块级字典 + `threading.RLock`/`Event` 管理（如 clarify 的 `_entries`/`_session_index`、cron 的心跳事件），所有读写均加锁保护。
- 长耗时操作（cron run、clarify 等待）通过周期性 activity 心跳（`touch_activity_if_due` 或自定义 heartbeat loop）防止 gateway inactivity watchdog 误杀。
- 平台差异通过条件分支处理（macOS 用 afplay、Termux 用 termux-microphone-record、WSL/Docker/SSH 检测），并以 warnings/notices 区分硬阻断与提示信息。
