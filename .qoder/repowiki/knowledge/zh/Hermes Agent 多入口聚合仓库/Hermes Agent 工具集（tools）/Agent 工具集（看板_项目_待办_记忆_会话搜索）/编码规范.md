- 工具通过 `tools.registry.registry.register(name, toolset, schema, handler, ...)` 集中声明，handler 仅做参数解包后委托给同模块的业务函数。
- 对外部依赖（kanban_db、projects_db、SessionDB、auxiliary_client 等）采用函数内局部 import，使模块可在无对应后端的环境中正常导入。
- 错误返回统一使用 `tools.registry.tool_error(...)` 包装结构化 JSON，避免直接抛出异常中断模型调用链。
- 敏感文本在落库前经 `agent.redact.redact_sensitive_text` 或 memory 的威胁模式扫描进行脱敏/拦截。
- 文件 I/O 使用文件锁（fcntl/msvcrt .lock）+ 原子写入（临时文件 + os.replace）保证并发安全，并在检测到外部漂移时回滚并返回 `.bak` 路径。
- 长列表/结果集通过显式 limit、截断标记（如 `truncated`、`next_limit`、`content_truncated`）控制响应体积，防止上下文膨胀。
