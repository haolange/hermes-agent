本模块由五个相互独立的工具文件组成，每个文件围绕一个领域能力实现：
- `kanban_tools.py`：基于 `hermes_cli.kanban_db` 的看板生命周期工具（show/list/complete/block/heartbeat/comment/attach），通过 `_check_kanban_mode` / `_check_kanban_orchestrator_mode` 按 `HERMES_KANBAN_TASK` 环境变量和 profile toolsets 配置动态开关；内置委派子代理拒绝、worker 任务所有权校验、goal judge 完成门控、自动心跳与评论注入等安全与运行时桥接逻辑。
- `project_tools.py`：对 `hermes_cli.projects_db` 的只读/写入封装，提供 project_list/create/switch，并通过 GUI 回调 `set_project_workspace_callback` 联动桌面侧工作区切换。
- `todo_tool.py`：纯内存 `TodoStore`（每 AIAgent 实例一份），支持 merge/replace 模式、内容截断与上下文压缩后的注入格式，通过 `registry.register` 以 `toolset="todo"` 暴露。
- `memory_tool.py`：基于 `MEMORY.md`/`USER.md` 的文件级持久记忆，`MemoryStore` 维护系统提示冻结快照与实时条目双状态，使用 fcntl/msvcrt 文件锁、原子写入、外部漂移检测与 `tools.write_approval` 写门禁，支持 add/replace/remove/batch 操作。
- `session_search_tool.py`：基于 `hermes_state.SessionDB` 的 FTS5 会话检索，单一入口 `session_search` 根据参数推断 discovery/scroll/read/browse 四种调用形态，支持跨 profile 读取、自动化来源降权与 lineage 去重。
所有工具均通过 `tools.registry.registry.register` 注册到全局 registry，错误统一经 `tools.registry.tool_error` 返回结构化 JSON，依赖方向单向指向 hermes_cli / hermes_state / agent 子系统，模块内部无横向耦合。
