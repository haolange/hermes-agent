模块由六个协作文件组成，按职责分层：
- `mcp_tool.py` 是核心入口，维护一个独立 daemon 线程上的 asyncio 事件循环 `_mcp_loop`，每个 MCP 服务器作为长生命周期 Task 运行；通过 `run_coroutine_threadsafe` 将工具调用调度到该循环，支持 stdio、HTTP/StreamableHTTP、SSE 三种传输，并负责工具描述扫描、图片/音频资源缓存、环境变量白名单过滤、错误信息脱敏、重连退避与 keepalive。
- `mcp_oauth.py` 实现 OAuth 2.1 授权码+PKCE 流程：`HermesTokenStorage` 以 `HERMES_HOME/mcp-tokens/<server>.json(.client.json/.meta.json)` 格式持久化令牌/客户端元数据；通过本地 `http.server.HTTPServer` 监听回调端口，支持浏览器自动打开、SSH 隧道提示和 stdin 粘贴回传；使用 `contextvars` 在后台发现线程与 MCP 事件循环线程之间传播交互性开关。
- `mcp_oauth_manager.py` 提供进程级单例 `MCPOAuthManager`，集中管理 per-server 的 `OAuthClientProvider` 实例，实现 mtime 磁盘变更检测（外部 cron 刷新令牌后热加载）、401 并发去重（共享 `pending_401` futures），并通过子类化 SDK 的 `OAuthClientProvider` 注入预取 PRM/ASM 元数据与 `invalid_client` 毒化客户端注册自愈。
- `mcp_dashboard_oauth.py` 定义 `DashboardOAuthFlow` dataclass，把浏览器回调从本地 HTTP 监听桥接到已认证的 dashboard 会话，通过 `threading.Event` + `ContextVar` 在 dashboard 与 MCP 流程间传递授权 URL 与回调结果。
- `mcp_schema_cache.py` 用 `HERMES_HOME/cache/mcp_schema_cache.json` 缓存每服务器的工具 schema，键为配置指纹（command/args/url/tools_filter 的 SHA256），使 dashboard 空闲启动时也能注册工具而不必拉起子进程。
- `mcp_stdio_watchdog.py` 是独立的 POSIX 监督脚本，被 `mcp_tool.py::_wrap_command_with_watchdog` 包装 stdio 命令，通过轮询 `getppid()` 检测父进程死亡，并以 SIGTERM→SIGKILL 终止子进程组，防止硬退出产生僵尸 MCP 子进程。
依赖方向：`mcp_tool.py` → `mcp_oauth.py` / `mcp_oauth_manager.py` / `mcp_schema_cache.py` / `mcp_stdio_watchdog.py`；`mcp_oauth_manager.py` 反向 import `mcp_oauth.py` 中的存储与回调构造器；dashboard 桥接通过 `get_dashboard_oauth_flow()` 上下文变量解耦。
