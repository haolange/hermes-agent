- 对外部可选依赖（`mcp` SDK、`gateway.platforms.base`、`pydantic`）采用 try/except ImportError 延迟导入，并在模块顶部设置 `_*_AVAILABLE` 标志位，缺失时降级为 no-op。
- 所有对磁盘的敏感写操作（OAuth 令牌、元数据、schema 缓存）使用原子写入模式：先写临时文件再 `os.replace`，并对目录设置 0o700/0o600 权限。
- 跨线程/协程边界的状态传播统一通过 `contextvars.ContextVar`（如 `_oauth_interactive_enabled`、`_oauth_interactive_forced`、`_current_dashboard_flow`），而非 `threading.local`，以支持 `run_coroutine_threadsafe` 调度的协程继承上下文。
- per-server 状态（OAuth provider、401 处理、schema 缓存）均以 server_name 为 key 的字典缓存，并在 URL 或配置变化时显式失效重建。
- 错误消息返回给 LLM 前统一经过 `_sanitize_error` 正则脱敏，移除 GitHub PAT、Bearer token、API_KEY 等凭据片段。
- stdio 子进程的环境变量通过 `_build_safe_env` 白名单过滤（PATH/HOME/XDG_* 及 secret-source 标记变量），并额外追加用户配置的 `env:` 块。
