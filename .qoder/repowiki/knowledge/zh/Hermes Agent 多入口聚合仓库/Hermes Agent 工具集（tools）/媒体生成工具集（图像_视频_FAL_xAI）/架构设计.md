本模块由四个并列的工具文件组成，按后端划分职责：
- `image_generation_tool.py`：FAL.ai 图像生成统一入口，通过模块级 `FAL_MODELS` 目录声明每个模型的尺寸风格（`image_size_preset` / `aspect_ratio` / `gpt_literal`）、默认参数、`supports` 白名单和可选编辑端点；`_build_fal_payload` / `_build_fal_edit_payload` 将统一输入翻译为模型特定负载并过滤到白名单；通过 `_submit_fal_request` 在直连 FAL 与 Nous 托管网关之间切换，支持 Clarity Upscaler 后处理。
- `video_generation_tool.py`：后端无关的统一 `video_generate` 工具，依赖 `agent.video_gen_provider` ABC 与 `agent.video_gen_registry` 插件注册表，运行时根据活跃 provider 动态构建 schema 描述，并将参数委派给具体插件实现。
- `flux3_video_tool.py`：直接对接 Nous 托管 BFL 网关的异步工具集（text/image/keyframes/video continuation + get_result），自行实现提交→轮询→下载→落盘的完整工作流，包含上传引用替换、SSRF 安全下载、超时/重试/节流策略以及结果本地保存。
- `xai_video_tools.py`：针对 xAI Imagine 的视频编辑/扩展专用工具，仅当 `video_gen.provider == 'xai'` 时可用，委托 `plugins.video_gen.xai` 执行实际调用。
所有工具均通过 `tools.registry.registry.register` 注册到 `video_gen` / `image_gen` toolset，并由各自的 `check_fn` 控制可见性。
