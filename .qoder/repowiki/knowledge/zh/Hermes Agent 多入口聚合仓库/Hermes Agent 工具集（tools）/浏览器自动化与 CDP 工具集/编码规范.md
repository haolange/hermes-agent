- 重依赖（如 `requests`、`call_llm`、`websockets`、`hermes_cli.config`）采用模块级 `__getattr__` 或函数内延迟导入，避免冷启动开销和循环导入。
- 配置读取统一通过 `read_raw_config()` + `cfg_get()` 包装，失败时回退到默认值并记录 debug 日志，结果用模块级 `_cached_*` + `_*_resolved` 标志缓存。
- 工具函数返回统一 JSON 字符串格式，成功走 `{"success": True, ...}`，失败走 `tools.registry.tool_error(...)` 构造错误体，便于上层统一解析。
- SSRF/私有页面保护通过 `browser_tool._eval_ssrf_guard_active`、`_is_always_blocked_url`、`_is_safe_url` 等共享守卫函数在各后端（browser_tool、browser_cdp、browser_camofox）中复用，而非各自实现 URL 检查。
- CDP 相关日志与异常消息统一经 `agent.redact.redact_cdp_url` / `redact_sensitive_text` 脱敏后再输出，防止 CDP URL 中的 token/userinfo 泄露到日志。
- CDP 操作通过 `CDPSupervisor` 的 `safe_schedule_threadsafe` 将协程调度到其专属事件循环执行，外部线程以同步方式等待 Future 结果，保持工具接口为纯同步。
