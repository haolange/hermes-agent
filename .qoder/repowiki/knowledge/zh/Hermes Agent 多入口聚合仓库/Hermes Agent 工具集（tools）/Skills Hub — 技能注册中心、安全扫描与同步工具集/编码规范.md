- 所有磁盘路径访问前通过 `_normalize_bundle_path` / `_validate_*` 系列函数进行白名单校验，拒绝绝对路径、`..` 穿越、Windows 盘符及非预期嵌套。
- 关键副作用（rmtree、删除、安装）前调用专用守卫函数（如 `_validate_delete_target`、`_is_path_redirect`、`should_allow_install`）进行防御性检查。
- 共享状态（技能目录、Hub 目录、锁文件、审计日志、索引缓存）通过 `_override` + `_DYNAMIC_PATH_RESOLVERS` + `__getattr__` 模式延迟解析，使单进程多 profile 运行时能按活跃 profile 切换。
- 易变 JSON/清单文件（`.usage.json`、`.bundled_manifest`）统一采用 tempfile + atomic_replace/os.replace 原子写入，避免中断导致损坏。
- 跨进程并发通过 fcntl（Unix）或 msvcrt.locking（Windows）的文件锁序列化 `.usage.json` 的读-改-写周期。
- 对外部可选依赖（如 `tools.skills_guard`、`agent.skill_utils`、`hermes_cli.config`）采用 try/except ImportError 或运行时 import，确保打包/更新场景下低层模块仍可运行。
