模块按职责划分为多个独立文件，围绕 `~/.hermes/skills/` 这一单一事实源组织：
- `skills_tool.py`：本地技能发现与渐进式披露（`skills_list` 仅返回元数据，`skill_view` 按需加载正文及引用文件），含会话级缓存与平台/环境过滤。
- `skills_hub.py`：Hub 核心库，定义 `SkillSource` ABC 及其 `GitHubSource` 实现（默认 taps 列表 + 可选额外 tap），通过 `GitHubAuth` 支持 PAT / gh CLI / GitHub App JWT 三种认证；维护 `.hub` 子目录（lock.json、quarantine、audit.log、taps.json、index-cache）并负责 SSRF 防护的 HTTP 获取。
- `skills_guard.py`：基于正则的模式扫描器，输出 `ScanResult`（含 `Finding`），配合 `INSTALL_POLICY` 表按 `builtin/trusted/community/agent-created` 信任级别决定 allow/block/ask。
- `skills_sync.py`：将仓库内 `skills/` 与 `optional-skills/` 同步到用户目录，使用 v2 清单 `~/.hermes/skills/.bundled_manifest`（`name:origin_hash`）跟踪变更，尊重外部 dirs 与 curator suppressed 名单。
- `skills_sync_client.py`：组织级同步客户端，封装 propose/pull 等远端操作。
- `skill_manager_tool.py`：Agent 可调用技能 CRUD（create/edit/patch/delete/write_file/remove_file），在写前执行 `_background_review_write_guard`、`_org_mirror_write_guard`、`_pinned_guard`、`_security_scan_skill` 等多层守卫，并通过 `contextvars` 记录 read-before-write 路径以限制后台审阅分支的写入面。
- `skill_usage.py`：持久化 `~/.hermes/skills/.usage.json` 侧车文件，维护 active/stale/archived 生命周期状态、pin 标记、curator-managed 标记，并使用 fcntl/msvcrt 进程锁保证并发安全。
- `skill_provenance.py`：通过 `contextvars.ContextVar` 区分 foreground 与 background_review 写来源，供 skill_manager 判定是否允许自主编排修改。
- `skills_ast_audit.py`：对技能 AST 做审计（静态分析入口）。
依赖方向单向收敛：`skills_hub` → `skills_guard`；`skill_manager_tool` → `skills_guard` + `skill_usage` + `skill_provenance`；`skills_sync` → `skill_usage`；各文件不互相反向依赖，保持清晰的职责边界。
