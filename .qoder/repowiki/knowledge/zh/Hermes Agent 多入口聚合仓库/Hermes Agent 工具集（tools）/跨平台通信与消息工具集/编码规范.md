- 每个工具文件以 `SCHEMA` 常量定义 JSON Schema，并在文件末尾通过 `registry.register(name=..., toolset=..., schema=..., handler=..., check_fn=..., emoji=...)` 注册到全局注册表。
- 对外部 SDK（lark_oapi、telegram、aiohttp、yuanbao adapter 等）采用函数内 lazy import，避免模块级导入导致冷启动耗时或 ImportError。
- 工具处理器统一返回 JSON 字符串，成功用 `json.dumps({...})` 或 `tool_result(...)`，失败用 `tool_error(...)` 包裹错误信息。
- 敏感信息（token、chat_id、URL 参数）在错误输出前经 `_sanitize_error_text` / `redact_sensitive_text` 脱敏后再返回给模型。
- 平台适配层通过 `gateway.platform_registry` 的 `standalone_sender_fn` 解耦 live adapter 与 standalone/cron 两种运行上下文，发送逻辑先尝试 runner.adapter，再回退到 registry entry。
- 配置读取统一通过 `agent.secret_scope.get_secret` 获取环境变量/密钥，而非直接读 os.environ，保证支持 profile 隔离。
