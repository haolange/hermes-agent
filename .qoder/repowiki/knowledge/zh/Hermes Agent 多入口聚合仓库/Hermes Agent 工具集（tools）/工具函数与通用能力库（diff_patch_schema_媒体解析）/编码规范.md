- 对外部副作用（git 调用、网络下载、文件系统读写、终端 exec）统一封装在私有函数中，公共 API 只负责参数校验与结果聚合，失败时返回结构化错误而非抛出未分类异常。
- 对传入的 schema/工具列表一律先 `copy.deepcopy` 再原地修改，保证调用方持有的原始注册表不被污染。
- 通过延迟 import（在函数体内 `from tools.xxx import ...`）打破模块间的循环依赖，尤其是 `patch_parser` ↔ `fuzzy_match` 之间。
- 使用自定义异常类族（如 `ImageResolutionError` 的子类 `SourceUnsafe`/`SourceTooLarge`/`NotAnImage`/`UnsupportedScheme`）区分不同失败原因，便于调用方针对性处理。
- 通过 `permitted` 元组参数（默认 `("image",)`）在同一解析入口上复用图像与视频的读取逻辑，仅在最终 `_finalize` 处根据标记进行类型判定。
- 对不可信输入（属性键、URL、patch hunk）采用“白名单/正则匹配 + 失败即拒绝”的保守策略，并在日志中记录被丢弃的具体值以便审计。
