- 对外暴露的共享可变状态（活跃子代理表、异步记录表、暂停标志）统一通过模块级 `threading.Lock` 保护，并以 `with _lock:` 块内读写，避免竞态。
- 配置读取采用 `_load_config()` + 环境变量回退 + 默认值的三段式模式（如 `max_concurrent_children`、`child_timeout_seconds`、`max_spawn_depth`），对非法值记录 warning 后降级到默认。
- 所有 I/O 路径（文件写入、SQLite 事务、网络请求）包裹 try/except 并降级为 debug 日志，确保委派核心流程不被辅助功能中断。
- 敏感信息在落盘前统一经 `_redact` / `_sanitize_tool_target` 脱敏，尤其是位于只读挂载目录 `cache/delegation/live` 下的 live transcript。
- 异步委派的生命周期通过 SQLite 行上的 `delivery_state`（pending → delivered / dropped）与 `delivery_claim` 原子转移，配合 `claim_event_delivery` / `release_completion_delivery` 实现多消费者重试与最终丢弃。
- 外部可选依赖（`jsonschema`、`hermes_cli.auth`、`agent.secret_scope`）采用运行时 import 并捕获异常降级，保证模块在无对应环境时仍可工作。
