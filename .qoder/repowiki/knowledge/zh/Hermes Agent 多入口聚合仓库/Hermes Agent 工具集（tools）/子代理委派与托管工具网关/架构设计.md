模块按职责拆分为四个协作层：
- 委派核心（delegate_tool.py）：维护进程级活跃子代理注册表（`_active_subagents` + `_spawn_pause_lock`），提供 `steer_subagent` / `interrupt_subagent` / `list_active_subagents` 等线程安全 API；通过 `_build_child_agent` 裁剪父 toolset（`DELEGATE_BLOCKED_TOOLS`）、注入角色提示（leaf/orchestrator）、限制最大深度（`MAX_DEPTH`）和并发度（`max_concurrent_children`），并通过 `progress_fn` 向心跳监控暴露进度。
- 异步委派（async_delegation.py）：基于 `tools.daemon_pool.DaemonThreadPoolExecutor` 的守护线程池执行 `runner()`，使用 SQLite `state.db::async_delegations` 持久化任务状态、投递声明（claim/release/drop）与恢复未交付完成事件；内置独立监控线程根据 `progress_fn` 返回的 token 检测停滞并触发中断。
- 可观测性（delegation_live_log.py + delegation_output_schema.py）：`LiveTranscriptWriter` 为每个子任务在 `<hermes_home>/cache/delegation/live/<id>/task-*.log` 追加一行式事件流，所有写入经 `_redact` 脱敏且永不抛异常；`delegation_output_schema.py` 将 JSON Schema 以 OUTPUT CONTRACT 块注入子上下文，并在结果上做一次 bounded retry（`MAX_SCHEMA_RETRIES=1`）。
- 托管网关（managed_tool_gateway.py + tool_backend_helpers.py）：从 `auth.json` 或 `TOOL_GATEWAY_USER_TOKEN` 解析 Nous 访问令牌，按 `TOOL_GATEWAY_DOMAIN`/`SCHEME` 构建 vendor 网关 URL，提供 `ManagedToolGatewayConfig` 数据类与 `build_managed_media_uploader`（预签名 PUT 协议）；`tool_backend_helpers.py` 集中 Modal/浏览器后端选择、凭据解析（`resolve_provider_secret` 走 secret_scope → .env → credential pool）与 entitlement 检查。
依赖方向单向：委托核心 → 异步委派 → 可观测性；托管网关与后端助手被各工具消费，不反向引用委托逻辑。
