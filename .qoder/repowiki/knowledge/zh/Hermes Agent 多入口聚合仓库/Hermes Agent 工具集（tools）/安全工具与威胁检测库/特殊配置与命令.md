tirith 自动安装到 `$HERMES_HOME/bin/tirith`，首次运行缺失时在后台线程下载 GitHub Release 并通过 SHA-256（可选 cosign 签名）校验；可通过 `TIRITH_BIN`、`TIRITH_ENABLED`、`TIRITH_TIMEOUT`、`TIRITH_FAIL_OPEN` 环境变量覆盖行为。OSV 检查端点与缓存 TTL 分别由 `OSV_ENDPOINT`、`OSV_CHECK_CACHE_TTL` 控制。URL 私网访问可通过 `security.allow_private_urls` 或 `HERMES_ALLOW_PRIVATE_URLS=true` 全局关闭拦截。
