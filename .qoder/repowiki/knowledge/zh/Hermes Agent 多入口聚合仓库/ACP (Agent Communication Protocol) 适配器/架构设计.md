模块以 `server.HermesACPAgent`（继承自 `acp.Agent`）为核心，通过 `entry.py` 的 CLI 入口加载 `.env`、配置日志并启动 `acp.run_agent`；`session.SessionManager` 负责创建/恢复持久化到 `~/.hermes/state.db` 的 AIAgent 会话，维护 `SessionState` 并在 WSL/Windows 路径间做 cwd 转换。依赖方向单向：`server` → `session` + `events` + `tools` + `permissions` + `auth` + `provenance` + `edit_approval`，各子模块仅被 server 消费。
- `auth.py`：探测运行时 provider 并构造 ACP `AuthMethodAgent` / `TerminalAuthMethod`，供握手阶段使用。
- `events.py`：工厂函数 (`make_tool_progress_cb` / `make_thinking_cb` / `make_message_cb` / `make_step_cb`) 把 AIAgent 回调桥接到 ACP `session_update()`，跨线程用 `safe_schedule_threadsafe` 调度。
- `tools.py`：维护 hermes 工具名到 ACP `ToolKind` 的映射表，生成 `ToolCallStart/Progress/Complete` 及人类可读标题。
- `permissions.py`：把 Hermes 危险命令审批请求转换为 ACP `request_permission`，提供 allow_once/session/always/deny 选项并映射回 Hermes 语义。
- `edit_approval.py`：在 `write_file` / `patch` 执行前抽取 `EditProposal`，基于 ContextVar 绑定当前 ACP 上下文的自动审批策略（ask / workspace_session / session）。
- `provenance.py`：从 SessionDB 的 parent_chain 推导 `_meta.hermes.sessionProvenance`，向客户端暴露压缩/续接链信息。
- 资源处理集中在 `server.py` 中的 `_resource_link_to_parts` / `_embedded_resource_to_parts`，把 ACP 附件转为 OpenAI 兼容的 text/image_url 内容块。
