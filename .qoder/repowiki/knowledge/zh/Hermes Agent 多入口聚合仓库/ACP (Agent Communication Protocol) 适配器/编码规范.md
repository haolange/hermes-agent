- 所有对 `hermes_cli`、`acp`、`tools.*` 等可选/重型依赖采用函数内延迟 import，保证模块可被无依赖环境导入。
- 跨线程回调统一通过 `agent.async_utils.safe_schedule_threadsafe` 将协程调度到 ACP 事件循环，避免直接 await 工作线程上下文。
- 对外部 I/O（文件读取、数据库查询、网络请求）一律包裹 try/except 并记录 debug/warning 日志后优雅降级，不向上抛出异常。
- 路径与 cwd 在 Windows/WSL 场景下通过 `hermes_constants.translate_cwd_for_wsl_backend` / `windows_path_to_wsl` 统一归一化为 POSIX 形式后再传给底层工具。
- AIAgent 事件回调以工厂函数形式返回闭包（如 `make_tool_progress_cb`），捕获 conn/session_id/loop/tool_call_ids 等上下文，保持回调签名与 AIAgent 约定一致。
- 工具名称到行为分类通过集中字典/集合声明（如 `TOOL_KIND_MAP`、`_POLISHED_TOOLS`），新增工具只需扩展映射而非修改分支逻辑。
