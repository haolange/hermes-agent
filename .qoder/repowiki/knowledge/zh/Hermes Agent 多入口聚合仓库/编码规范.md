- 所有顶层入口文件（cli.py、run_agent.py、batch_runner.py、cron/scheduler.py 等）必须在模块最顶部 import hermes_bootstrap，以启用 Windows UTF-8 stdio 与 sys.path 加固。
- 第三方依赖在 pyproject.toml 中采用 == 精确版本锁定，并通过 [project.optional-dependencies] 与 tools/lazy_deps.py 实现按功能域延迟安装，避免污染核心依赖面。
- 跨进程日志通过 hermes_logging.setup_logging(mode=...) 初始化，并写入 ~/.hermes/logs/ 下的 agent.log 与 errors.log，Windows 下使用 concurrent-log-handler 解决多进程文件锁。
- 配置加载遵循 ~/.hermes/config.yaml → ./cli-config.yaml → 环境变量 的优先级链，并通过 load_hermes_dotenv 合并项目级 .env。
- 会话持久化统一经由 hermes_state.SessionDB 与 hermes_state_schema 定义的 SQLite schema，AIAgent 在首次 turn 时懒创建 session 行。
