- CJK 字符判定集中在 `cjk_is_cjk` 中，以码点区间判断 Hangul、CJK Unified Ideographs、Hiragana/Katakana 等范围，避免引入 Unicode 表。
- UTF-8 解码与 CJK 判定成对使用：先调用 `cjk_utf8_decode` 取 codepoint，再交给 `cjk_is_cjk` 分类，循环推进字节偏移。
- 对外部 tokenizer 回调采用包装结构体（`CjkTokenizer` + `CjkCallbackCtx`）持有 inner tokenizer 实例与回调函数指针，实现组合式分词。
- token 偏移通过 `CJK_CLAMP_END` 宏钳制到原始 token 的 `[iStart,iEnd)` 边界，保证 highlight 偏移不会越界。
- 构建脚本以 `set -euo pipefail` 严格模式执行，并通过 gcc `-E` 探测系统 sqlite3 头可用性来决定是否追加 `-Ivendor`。
