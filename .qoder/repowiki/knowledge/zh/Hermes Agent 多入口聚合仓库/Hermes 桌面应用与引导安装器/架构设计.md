本模块由三个子包组成，构成「安装 → 运行 → 共享」三层结构：
- `apps/desktop`（Electron 主进程 + Vite/React 渲染进程）：`electron/main.ts` 作为单入口，集中注册 IPC、窗口生命周期、后端启动流程（bootstrap-runner / primary-backend-startup）、SSH/远程连接、更新与自修复（update-*、windows-sandbox-fallback、bootstrap-repair-guard），并通过 `preload.ts` 暴露安全 API 给渲染层；渲染端位于 `src/`，按功能域拆分子目录（chat、shell、settings、plugins、themes、store、lib 等），通过 nanostores 状态管理并与后端通过 WebSocket/Gateway RPC 通信。
- `apps/bootstrap-installer`（Tauri + React/Vite）：前端 `src/routes/*` 展示安装进度/成功/失败页面，Rust 后端 `src-tauri/src/` 调用系统 shell 执行 `scripts/install.ps1`，通过 Tauri 插件（dialog/shell/process/opener）驱动安装流程，输出二进制名为 `Hermes-Setup.exe`。
- `apps/shared`：纯 TS 类型与工具库（billing-types、charge-settlement、json-rpc-gateway、websocket-url、skin），通过 `package.json` 的 `exports` 字段以子路径形式被 desktop 与 bootstrap-installer 引用，是前后端之间的契约层。
依赖方向严格单向：desktop 与 bootstrap-installer 均依赖 shared，二者之间无直接耦合；desktop 通过 electron-builder 打包为多平台安装包，bootstrap-installer 通过 tauri build 生成签名安装器。
