桌面端开发需先启动 Vite 渲染服务再启动 Electron：`npm run dev`（concurrently 同时跑 `dev:renderer` 与 `dev:electron`，后者用 `wait-on` 等待 5174 端口）；打包走 `npm run dist`（触发 `vite build` → `bundle-electron-main.mjs` → `stage-native-deps.mjs` → `run-electron-builder.mjs`）；Windows 引导安装器通过 `npm run tauri:build` 编译，产物重命名为 `Hermes-Setup.exe`；E2E 测试需在 headless 环境下执行 `cage -- npx playwright test e2e/`。
