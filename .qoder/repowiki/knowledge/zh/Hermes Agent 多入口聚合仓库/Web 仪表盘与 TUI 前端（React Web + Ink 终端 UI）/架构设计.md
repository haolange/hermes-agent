本模块包含两个并列的前端子工程：
- `web/`：基于 Vite + React 19 + react-router 8 的浏览器仪表盘。入口 `src/main.tsx` 依次包裹 `BrowserRouter`、`I18nProvider`、`ThemeProvider`、`SystemActionsProvider`，根组件 `App.tsx` 维护侧边栏布局并通过 `lazy()` 按需加载各 `pages/*` 路由页面；插件系统通过 `plugins/` 下的 manifest 注册表动态注入路由与导航项，`PluginPage`/`PluginSlot` 提供插槽式扩展点；聊天页在嵌入模式下以持久 host 方式挂载，避免 PTY/xterm 随路由切换销毁。
- `ui-tui/`：Node.js 终端应用，入口 `src/entry.tsx` 负责 TTY 检测、终端模式重置、优雅退出、内存监控与 `@hermes/ink` 渲染器启动；内部按职责分层：`app/`（状态机、Gateway 事件处理、会话生命周期、输入/提交核心）、`components/`（Ink 组件树）、`domain/`（消息/视图模型）、`lib/`（工具库）、`protocol/`（协议编解码）、`sdk/`（用户 Widget SDK）。依赖自研 `packages/hermes-ink` 作为 Ink 框架层，实现虚拟屏幕、事件分发、布局与渲染管线。
- 两子工程共享 `../apps/shared` 中的类型与协议定义，通过各自的 `GatewayClient` 与后端 WebSocket/gRPC 通信，形成“Web 管理面 + TUI 交互面”的双前端架构。
