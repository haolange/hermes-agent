- Web 侧路由页面统一放在 `pages/` 下并通过 `React.lazy` + `Suspense` 懒加载，由 `App.tsx` 集中注册到 `BUILTIN_ROUTES_CORE` 映射中。
- 全局状态通过 React Context（`contexts/*`）与自定义 hook（`use*`）暴露，如 `ProfileProvider`、`SystemActionsProvider`、`useProfileScope`、`useSystemActions`。
- TUI 侧将业务逻辑拆分为 `app/`（状态与流程）、`components/`（纯渲染）、`domain/`（数据模型）、`lib/`（无副作用工具），并在 `__tests__/` 中以同名 `.test.ts(x)` 文件覆盖。
- 插件化扩展采用 manifest + registry + slot 模式：Web 侧通过 `plugins/registry.ts` 加载外部 JS 并以 `PluginSlot` 注入到 header/backdrop/overlay 等位置；TUI 侧通过 `sdk/` 暴露 Widget SDK 供用户扩展。
- 所有可复用能力均抽取为独立模块并配套同目录 `.test.ts`，测试命名遵循 `<feature>.test.ts` 约定，便于 Vitest 自动发现。
- 主题与国际化通过 Provider 注入：Web 侧 `themes/context.tsx` 与 `i18n/context.tsx` 分别提供 `useTheme`/`useI18n`，TUI 侧通过 `theme.ts` 与 `content/*` 配置驱动 Ink 组件样式。
