根目录作为整个项目的装配层：pyproject.toml 通过 [project.scripts] 暴露 `hermes`、`hermes-agent`、`hermes-acp` 三个命令行入口，分别指向 hermes_cli.main、run_agent.main 与 acp_adapter.entry；每个入口在导入任何业务模块前必须先 import hermes_bootstrap，以完成 Windows UTF-8 stdio、sys.path 加固与惰性安装目标激活。运行时由 run_agent.py 中的 AIAgent 类承载对话主循环，并通过 model_tools / toolsets / tools / skills / plugins 等包按需发现与注册能力；gateway/run.py 与 tui_gateway/entry.py 则把同一套 AIAgent 暴露为 HTTP/WebSocket/JSON-RPC 网关，供 web_frontend、desktop_app、acp_adapter 消费。共享基础设施集中在根级 hermes_*.py（constants、logging、state schema/time/portability）与 utils.py，被所有子模块共同引用；构建与部署由 Dockerfile、docker-compose.yml、flake.nix、scripts/ 及 .github/workflows 统一编排。
