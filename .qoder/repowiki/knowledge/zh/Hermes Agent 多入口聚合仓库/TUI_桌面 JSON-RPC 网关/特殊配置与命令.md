入口为 `python -m tui_gateway.entry`（stdio 模式）或挂载 `tui_gateway.ws.handle_ws` 到 FastAPI/Starlette WebSocket 路由；可通过环境变量调优：`HERMES_TUI_GATEWAY_SHUTDOWN_GRACE_S`（优雅退出超时）、`HERMES_TUI_RPC_POOL_WORKERS`（RPC 线程池大小）、`HERMES_TUI_SLASH_TIMEOUT_S`（斜杠命令超时）、`HERMES_TUI_WS_ORPHAN_REAP_GRACE_S`（WS 孤儿回收宽限）、`HERMES_TUI_SIDECAR_URL`（Dashboard 侧车 WS 旁路）、`HERMES_TUI_GATEWAY_NO_FLUSH`（跳过 flush）。
