- 容器入口采用双路径设计：PID 1 走 s6-overlay `/init`，非 PID 1 走 `stage2-hook.sh` + `main-wrapper.sh` 直启，确保 Fly Machines、Nomad 等平台也能运行。
- Nix 包通过 `callPackage` 组合多个 `.nix` 片段（`python.nix`、`tui.nix`、`web.nix`、`sandbox.nix`），由 `packages.nix` 统一组装为 `perSystem.packages` 暴露。
- CI 脚本集中在 `scripts/ci/`，以独立 Python 模块形式被各 workflow 按需导入，避免在 workflow YAML 中内联逻辑。
- shell 脚本统一以 `#!/bin/sh` + `set -e` 开头，并使用 `shellcheck` 标注（如 `# shellcheck shell=sh`），保证跨 POSIX 兼容性。
- 可选能力通过环境变量（如 `HERMES_BUNDLED_SKILLS`、`HERMES_OPTIONAL_MCPS`、`HERMES_WEB_DIST`）注入而非硬编码路径，使同一二进制可在不同部署形态下复用。
- Docker 初始化阶段通过 `cont-init.d/` 编号前缀（如 `015-supervise-perms`、`02-reconcile-profiles`）控制执行顺序，服务编排通过 `s6-rc.d/` 的 `run`/`finish`/`type` 声明式描述。
