`nix develop` 会触发 `devShell.nix` 中收集所有 npm workspace 的 `package.json` 并统一执行 `npm i --package-lock-only` / `npm ci`；`docker run` 时若以非 PID 1 方式被托管平台包装，`entrypoint-dispatch.sh` 会自动降级为跳过 s6-overlay 的直接引导模式；`install.sh` 支持 `--manifest`/`--stage` 输出桌面引导阶段清单，并以 FHS 布局在 root 环境下安装到 `/usr/local/lib/hermes-agent`。
