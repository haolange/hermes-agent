本模块以 `conversation_loop.py` / `moa_loop.py` / `codex_runtime.py` 为入口编排单轮对话：turn 启动时由 `session_turn_lifecycle` 构建 turn context 并组装系统提示词（`prompt_and_reasoning`），随后进入 `tool_execution` 的工具调用循环；每次推理通过 `model_adapters`（Anthropic/Bedrock/Gemini Native）或 `transports/` 下的 OpenAI/Codex 传输层发起请求，错误与速率限制由 `error_retry_rate_limit` 统一处理；工具结果经 `context_and_compression` 注入引用并更新会话窗口；跨进程诊断与追踪由 `streaming_output`、`trace_upload` 和 `monitoring/` 采集；浏览器/图像/TTS/WebSearch 三类能力通过 `provider_registries` 按配置路由到具体实现；凭证由 `credential_management` 从 `secret_sources/` 多来源加载；LSP、健康检查、技能生成与验证分别由 `lsp/`、`monitoring/`、`pet/`、`verify/` 子包作为独立可插拔扩展挂载到同一运行时。
