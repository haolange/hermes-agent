模块由三个职责清晰的文件组成：
- `prompt_builder.py`：纯函数式、无状态的提示词片段库。集中定义身份（DEFAULT_AGENT_IDENTITY）、平台提示（PLATFORM_HINTS 字典覆盖 WhatsApp/Telegram/Discord/SMS/WebUI 等十余种通道）、工具使用指导（TOOL_USE_ENFORCEMENT_GUIDANCE、OPENAI_MODEL_EXECUTION_GUIDANCE、GOOGLE_MODEL_OPERATIONAL_GUIDANCE、PARALLEL_TOOL_CALL_GUIDANCE、TASK_COMPLETION_GUIDANCE）、计算机操作指导（computer_use_guidance 按 darwin/win32/linux 动态生成）以及中间转向标记（STEER_MARKER_OPEN/CLOSE）。通过 `_scan_context_content` + `tools.threat_patterns.scan_for_threats` 在注入前扫描 AGENTS.md/.cursorrules/SOUL.md 等上下文文件，拦截 prompt injection/promptware。
- `system_prompt.py`：提示词装配器。`build_system_prompt_parts` 将提示词切分为 stable/context/volatile 三块并返回 dict，`build_system_prompt` 将其拼接为完整字符串；通过 `_ra()` 延迟引用 `run_agent` 以兼容测试对 `run_agent.*` 的 patch。平台提示支持 config.yaml 中的 `platform_hints.<key>` 覆盖（replace/append/字符串简写），并通过 `_resolve_platform_hint` 应用。时间戳仅精确到日以保证缓存前缀稳定；Alibaba provider 会注入模型名修正行。
- `reasoning_summaries.py`：针对 OpenAI Responses API 转 chat wire 时丢失 `summary_index` 的问题，通过检测 `**Heading**` 加粗标题边界，在流式拼接前插入段落分隔，修复 `****` 粘连渲染。
依赖方向单向：`system_prompt.py` → `prompt_builder.py` → 外部 `tools.threat_patterns` / `agent.skill_utils` / `hermes_constants`；`reasoning_summaries.py` 独立无外部依赖。
