- 对外暴露的上下文/快照通过 dataclass 或纯函数返回不可变结构体（如 `TurnContext`、`build_activity_snapshot`），将副作用集中在 builder/finalizer 中。
- 对可选能力与测试 double 统一采用 `getattr(obj, 'xxx', None)` + `callable(...)` 守卫，确保 SimpleNamespace/MagicMock 不会触发 AttributeError。
- 长耗时或重型依赖（如 MCP 刷新、日志器、压缩估算）以条件分支 + 本地 import 延迟加载，避免冷路径引入开销。
- 可观测性输出通过统一的 activity snapshot 构造器聚合 timestamp/description/provenance/elapsed 字段，并保留短别名兼容旧消费者。
- 错误处理采用 try/except 包裹每个易失败的后置步骤（轨迹保存、资源清理、持久化、插件钩子），收集 `_cleanup_errors` 附加到 result 而非向上抛出，保证 final_response 始终返回。
- 通过显式注入回调/助手函数（如 `restore_or_build_system_prompt`、`install_safe_stdio`）解耦 `build_turn_context` 与 `conversation_loop`，消除模块间导入环。
