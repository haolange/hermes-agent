本模块按 turn 的三段式阶段切分 `run_conversation` 的单体逻辑：
- `session_activity.py` 提供纯观察型活动心跳契约（`ActivityProvenance` 枚举、`build_activity_snapshot`、60s 最小心跳间隔常量），仅负责时间戳+描述+来源的不可变快照，不持有状态。
- `turn_context.py` 通过 `TurnContext` dataclass 承载 turn 启动期产出的所有局部变量（user_message、messages、system_prompt、任务/轮次 ID、索引等），由 `build_turn_context` 顺序执行 stdio 保护、MCP 刷新、系统提示恢复、DB session 行创建、空闲/预检压缩决策、外部记忆预取等一次性前置工作；该函数通过显式注入回调参数避免与 `conversation_loop` 形成导入环。
- `turn_finalizer.py` 暴露 `finalize_turn`，承接主循环结束后的预算耗尽回退、轨迹保存、资源清理、会话持久化、中断后 tool 序列闭合、微压缩、插件钩子（transform_llm_output / post_lll_call / on_session_end）、上下文引擎通知以及最终 result 字典拼装。
依赖方向单向：`turn_finalizer` → `agent.conversation_loop`（仅运行时 import logger），`turn_context` → 压缩/记忆/模型元数据等子模块，三者均被上层 `conversation_loop` 组合调用，构成 turn 生命周期的可测试、可替换边界。
