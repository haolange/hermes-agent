模块由三个职责清晰的子文件组成：
- `learning_graph.py` 负责数据装配：扫描 base/profile 两个 skills 根目录下的 `SKILL.md`，解析 frontmatter 提取 `related_skills`、`category`、`metadata.hermes`，结合 `.usage.json` 中的使用计数生成 `SkillNode`；同时把 `memories/MEMORY.md` 与 `USER.md` 按 `§` 切分为 memory 卡片，并通过词法重叠（token 交集 + 精确名称匹配）在 memory 与 skill 之间建立边；最终输出包含 `nodes`、`edges`、`clusters`、`memory`、`stats` 的统一 payload。
- `learning_graph_render.py` 是纯 stdlib 的终端渲染层，完全复刻桌面端 `time-axis.ts` / `color.ts` / `geometry.ts` 的 recency 计算、年龄渐变 (`AGE_OLD_INK/AGE_MID_INK/AGE_NEW_INK`)、互补色 palette 与 golden-angle 类别着色；将节点按 day/month/year 粒度聚成 `_ChartBucket`，产出带比例条、轨迹 sparkline、标签行与元数据的 grid，并支持多帧预渲染 (`render_frames`) 供 TUI 播放。
- `learning_mutations.py` 提供用户侧 edit/delete 入口，通过稳定的 node id 协议（skill 用名称，memory 用 `memory:<source>:<index>`）反向定位磁盘位置，调用 `tools.skill_manager_tool`、`tools.memory_tool.MemoryStore`、`tools.skill_usage` 完成归档/重写，并在变更后清除 prompt 缓存以保证一致性。
依赖方向单向：mutations → learning_graph（复用 `_memory_cards` 做索引校验），render 仅消费 learning_graph 产出的 payload，三者均不互相耦合。
