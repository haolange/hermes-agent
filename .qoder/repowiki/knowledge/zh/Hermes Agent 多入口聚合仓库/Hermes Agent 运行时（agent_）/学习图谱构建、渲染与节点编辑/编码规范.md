- 对外暴露的 node id 采用统一协议：skill 节点直接使用技能名，memory 节点使用 `memory:<source>:<index>` 形式，便于跨模块稳定引用。
- 对可选外部依赖（`agent.skill_utils.parse_frontmatter`、`tools.skill_usage.load_usage`、`tools.memory_tool.MemoryStore`、`tools.skill_manager_tool._find_skill`）采用函数内 import 加 try/except 包裹，保证模块在无这些依赖时仍可加载。
- 时间戳处理统一通过 `_to_int_ts` / `_to_ts` 转换，兼容 int、float、ISO 字符串等多种来源，缺失时回退为 None。
- 渲染输出采用 `[text, style, alpha, hex?]` 四元组 Run 格式，style 键（`STYLE_SKILL`、`STYLE_MEMORY`、`STYLE_LABEL`、`STYLE_DIM`、`STYLE_BG`）由消费者映射到具体调色板，解耦语义与视觉。
- 错误路径统一返回 `{"ok": False, "message": str(exc)}` 的结构化响应，而非抛出异常，使 CLI/TUI/GUI 调用方无需捕获异常即可展示友好提示。
- 类别配色通过 golden-angle (137.508°) 等间隔分配 HSL hue，确保相邻类别颜色不冲突且与主题无关。
