- Provider/Registry 模式：浏览器、图像生成、TTS、WebSearch、Transcription 均采用 `<capability>_provider.py` + `<capability>_registry.py` 成对定义，通过注册表按名称解析后端。
- 模型适配层统一采用 `<vendor>_adapter.py` 将 Hermes 内部消息/工具协议转换为厂商特定 API，并在 `transports/` 中暴露统一的异步调用接口。
- 凭据与秘密源遵循 `secret_sources/base.py` 抽象基类 + `registry.py` 集中注册的插件式扩展方式。
- 所有对外部 I/O（网络、磁盘、stdout/stderr）均通过显式的守卫/代理（ssl_guard、file_safety、thread_scoped_output、stream_single_writer）包裹，避免隐式副作用。
- 遥测与诊断统一经由 `monitoring/emitter.py` 事件总线与 `trace_upload` 导出，而非在各组件内直接写日志。
