- 注册表使用模块级 `Dict[str, Provider]` 配合 `threading.Lock()` 保护读写，所有对外访问都先加锁再操作。
- `register_provider` 统一校验 Provider 类型与 `.name` 非空字符串，重注册时覆盖旧条目并记录 debug 日志。
- `list_providers` 总是返回按 `name` 排序的列表，`get_provider` 对传入 name 做 strip 后查找。
- 活动 Provider 解析遵循“显式配置优先且不过滤可用性，自动回退路径才过滤 `is_available()`”的策略，并通过 `_is_available_safe` 包裹避免异常传播。
- 每个模块提供 `_reset_for_tests` 钩子用于测试环境清空注册表。
