模块由三个职责正交的 Python 文件组成：
- `trace_upload.py`：以 `upload_session_trace` 为入口，从 `hermes_state.SessionDB` 读取会话消息，通过 `_content_to_blocks` / `_tool_calls_to_blocks` 转换为 Claude Code JSONL 格式（每条非 system 消息一行），经 `agent.redact.redact_sensitive_text` 强制脱敏后，用 `huggingface_hub.HfApi` 推送到用户私有 `{user}/hermes-traces` 数据集的 `sessions/{session_id}.jsonl`；所有外部调用（token 解析、whoami、create_repo、upload_file）均被 try/except 包裹，函数始终返回人类可读状态字符串而不抛出异常。
- `moa_trace.py`：在配置 `moa.save_traces` 开启时，将每次 MoA 引用扇出（缓存未命中）的完整 turn 追加写入 `<hermes_home>/moa-traces/<sanitized_session_id>.jsonl`；记录每个 reference 的 `_RefAccounting`（输入消息、输出、usage、cost）和 aggregator 的输入/输出及 `output_location`（inline / inline_from_stream / assistant_message_in_session_db），写失败仅 debug 日志，绝不中断主流程。
- `insights.py`：`InsightsEngine` 类直接操作 `SessionDB._conn`，通过一组类级常量 SQL（含 `INDEXED BY idx_messages_assistant_calls_by_session` 部分索引提示）查询 sessions、messages、session_model_usage 表，按 model/platform/tool/skill/activity/top_sessions 维度聚合，并借助 `agent.usage_pricing.estimate_usage_cost` 估算 USD 成本；构造器会探测索引是否存在并在只读旧库上动态剥离 `INDEXED BY` 子句以保证兼容。
依赖方向：三者均向下依赖 `hermes_state`（SQLite 访问）、`hermes_constants`（hermes_home）、`agent.usage_pricing`（成本估算）与 `agent.redact`（敏感信息脱敏），彼此之间无相互导入。
