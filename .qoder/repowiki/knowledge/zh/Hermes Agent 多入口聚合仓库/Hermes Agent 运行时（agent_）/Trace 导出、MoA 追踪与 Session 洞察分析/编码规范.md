- 对外暴露的入口函数（如 `upload_session_trace`、`save_moa_turn`）采用 try/except 包裹所有 I/O 与网络调用，并以返回人类可读状态字符串或静默记录日志的方式处理错误，保证上层调用永不因追踪/上传失败而崩溃。
- 敏感文本在序列化到 trace 前统一通过 `agent.redact.redact_sensitive_text(text, force=True)` 进行强制脱敏，图片内容替换为 `[image omitted]` 占位符以避免 base64 泄露。
- SQL 查询以类级常量字符串定义（如 `_GET_SESSIONS_ALL`、`_GET_TOOL_CALLS_WITH_SOURCE`），并通过 `INDEXED BY` 显式绑定部分索引，同时在构造期探测索引存在性并在缺失时动态剥离该子句以保持向后兼容。
- 时间窗口查询统一通过传入 `cutoff = time.time() - (days * 86400)` 参数过滤 `started_at`，并提供带/不带 `source` 过滤的两套查询分支，保持统计口径一致。
- MoA 追踪记录以 JSONL 行追加写入，字段名使用 snake_case 且对可选字段使用 `getattr(acct, ..., None)` 安全取值，确保缺失属性不会导致写入失败。
