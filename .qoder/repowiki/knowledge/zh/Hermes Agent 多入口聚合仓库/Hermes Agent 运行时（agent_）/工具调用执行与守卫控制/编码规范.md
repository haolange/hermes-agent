- 所有可配置常量集中定义在模块级 frozenset / 数值常量（如 `_NEVER_PARALLEL_TOOLS`、`IDEMPOTENT_TOOL_NAMES`、`_DEFAULT_*`），并通过 `from_mapping` 类方法从 YAML 映射构建配置对象。
- 对外部或可选依赖采用延迟 import（如 `tools.approval`、`model_tools`、`hermes_cli.middleware`），避免循环导入并在缺失时回退到安全默认值。
- 守卫与调度逻辑以数据类（`ToolCallGuardrailConfig`、`LoopCapConfig`、`ToolCallSignature`、`ToolGuardrailDecision`）承载状态与决策，调用方只消费返回值而不直接修改内部计数。
- 对模型生成的 JSON 参数统一通过 `json.loads` 解析并返回 `(args, error_json)` 二元组，解析失败时构造结构化错误消息而非抛出异常。
- 高风险工具输出通过 `make_tool_result_message` 统一包裹 `<untrusted_tool_result>` 标签，并对嵌入的定界符进行 neutralize 以防止逃逸。
- 并发调度通过 `threading.Condition` + 单调递增的 `next_start_order` 实现有序启动门控，配合 `batch_abandoned` Event 保证批放弃后不再派发已排队工具。
