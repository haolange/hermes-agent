- 对外暴露的模型统一使用 `@dataclass(frozen=True)` 定义不可变数据结构（如 BillingBlock、UsageModel、UsageBar、CardInfo、BillingState 等）。
- 所有面向远端数据的构建函数采用 fail-open 模式：任何异常或字段缺失都返回可用度为 False 的默认实例，绝不向调用方抛出异常。
- 通过 `try: from hermes_cli.*` 的延迟导入隔离可选依赖，使本模块可在无 CLI 环境（如纯测试）中安全导入。
- 金额一律以 `decimal.Decimal` 在模块内流转，仅在最终显示时格式化为字符串（`format_money` / `_fmt_usd`），避免浮点精度问题。
- 提供基于 `os.getenv` 的环境变量开关（`HERMES_DEV_*_FIXTURE`）将真实网络请求短路为预置 fixture，便于离线验证各 UI 分支。
- 通过集中注册表（`_PROVIDERS` tuple + `_BY_SLUG` 索引）管理外部 provider 映射，新增 provider 只需追加条目而无需改动解析逻辑。
