本模块由三个并列的 provider 适配器组成，每个文件独立封装一个后端的具体实现，并通过统一的 OpenAI 风格消息/工具格式向上暴露接口：
- `anthropic_adapter.py`：基于 `anthropic` SDK 的 Messages API 客户端构建器（`build_anthropic_client`、`build_anthropic_bedrock_client`），通过 `_is_oauth_token`、`_requires_bearer_auth`、`_is_third_party_anthropic_endpoint`、`_is_kimi_coding_endpoint`、`_is_nous_portal_endpoint`、`_is_azure_anthropic_endpoint` 等函数按 base_url 与 key 前缀动态选择 x-api-key / Bearer / OAuth + Claude Code UA 认证路径，并维护 `_ANTHROPIC_OUTPUT_LIMITS`、`ADAPTIVE_EFFORT_MAP`、`_LEGACY_MANUAL_THINKING_CLAUDE_SUBSTRINGS` 等表驱动配置以区分 Claude 4.6/4.7+ 自适应思考、xhigh effort、fast mode、beta header 等能力。
- `bedrock_adapter.py`：基于 boto3 的 Converse API 适配器，提供 `convert_messages_to_converse` / `normalize_converse_response` / `stream_converse_with_callbacks` 完成 OpenAI ↔ Converse 双向转换；通过 `_bedrock_runtime_client_cache`、`_bedrock_control_client_cache` 按 region 缓存 client，并内置 `is_stale_connection_error`、`is_streaming_access_denied_error` 进行连接失效与 IAM 流式权限检测；`resolve_aws_auth_env_var` / `has_aws_credentials` / `resolve_bedrock_region` 复用 AWS 默认凭证链。
- `gemini_native_adapter.py`：绕过 Google OpenAI 兼容端点，直接对 `generativelanguage.googleapis.com/v1beta` 发送 `generateContent` 请求；`build_gemini_request` 将 OpenAI messages/tools/tool_choice/thinking_config 映射为 Gemini contents/systemInstruction/tools/toolConfig/generationConfig，`translate_gemini_response` / `translate_stream_event` 将响应与 SSE 事件转回 OpenAI 风格的 `SimpleNamespace`；通过 `probe_gemini_tier` 探测免费配额并在 429/401 时附加用户可操作提示。
依赖方向单向向下：适配器仅依赖底层 SDK（anthropic/boto3/httpx）与共享工具（`utils.base_url_host_matches`、`agent.secret_scope`、`agent.gemini_schema.sanitize_gemini_tool_parameters`），不反向被 SDK 依赖；各适配器之间相互独立，由上层运行时根据 provider 选择加载。
