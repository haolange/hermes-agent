- 每个外部凭证来源以独立的 `RemovalStep` 注册函数形式声明，remove_fn 仅返回 `RemovalResult(cleaned/hints/suppress)`，不直接修改调用方状态。
- 凭证池内所有可变操作（select、mark_exhausted、_replace_entry、_persist）均通过 `threading.RLock` 保护，并在注释中明确 self-locking 语义以避免 deferred refresh 路径竞态。
- 对外部第三方凭据文件（claude_code、qwen-cli、codex 等）采用“抑制而非删除”的策略，通过 `suppress_credential_source` 阻止下次 load_pool 重新播种，保持第三方 CLI 可用。
- 写入 auth.json 前统一经 `sanitize_borrowed_credential_payload` 过滤，借用型来源仅保留元数据与 `secret_fingerprint`，Hermes 自有来源（manual、hermes_pkce、device_code 等）透传。
- 错误冷却时间根据 HTTP 状态码与 classified failure_reason 动态计算，单凭据场景下对瞬态限流（429/403/5xx）缩短至 1 分钟，计费类失败（402/billing）保持长 TTL。
- 配置读取使用 `_load_config_safe` 包装 `load_config_readonly`，异常时返回 None 降级，避免配置加载失败阻断凭证池热路径。
