- 对外暴露成对的 classify/get_* 函数：一个返回结构化分类结果（如 `classify_cross_profile_target`），另一个返回面向模型/用户的警告消息（如 `get_cross_profile_warning`），由调用方决定展示或放行。
- 敏感路径判定统一先 `Path.expanduser().resolve()` 再比对，避免相对路径与符号链接导致的绕过。
- TLS 相关错误统一通过 `_ssl_err` 构造 `SSLConfigurationError`，并在错误信息末尾附加 `HERMES_SKIP_SSL_GUARD` 与 `hermes doctor --fix` 等可操作修复提示。
- 可选的环境变量开关采用“宽松布尔”匹配集合（如 `_SKIP_VALUES = {"1","true","yes","on"}`、`{"false","0","no","off"}`）实现大小写无关的开关解析。
- 对可能失败的外部依赖（如 `import certifi`、`from hermes_constants import get_hermes_home`）使用 try/except 包裹并提供降级默认值，保证守卫在缺失依赖时不中断主流程。
