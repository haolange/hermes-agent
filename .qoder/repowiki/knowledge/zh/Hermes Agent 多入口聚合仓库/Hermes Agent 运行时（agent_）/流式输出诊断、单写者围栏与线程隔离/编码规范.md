- 对外暴露的辅助函数均采用 try/except 包裹并 swallow 异常，确保调用方不受诊断/围栏逻辑失败影响（best-effort 语义）。
- 通过 `getattr(obj, '_xxx', None)` + `callable` 检查以 duck-type 访问可选的 agent 内部钩子，避免硬依赖具体类。
- 诊断数据使用可变 dict 作为 per-attempt 上下文，由调用方在流生命周期内原地填充并在重试点读取。
- 日志输出统一走 `logger.warning`/`logger.debug` 并附带结构化字段（attempt、provider、base_url、error_type、chain、bytes/chunks/ttfb），用户可见提示则通过 `agent._buffer_status` 单独生成。
- 全局可变的进程级设施（如 `sys.stdout`/`stderr` 代理）通过带锁的 `_ensure_installed` 单例安装，且永不卸载以避免竞态。
