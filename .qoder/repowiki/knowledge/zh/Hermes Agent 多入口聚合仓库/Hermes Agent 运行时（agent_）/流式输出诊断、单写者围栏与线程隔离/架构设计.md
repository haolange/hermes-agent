本模块由三个相互独立的工具文件组成，均被上层 `AIAgent`/`chat_completion_helpers`/`codex_runtime` 等调用方通过函数接口消费，不持有状态：
- `stream_diag.py`：定义 `STREAM_DIAG_HEADERS` 白名单及 `stream_diag_init`/`stream_diag_capture_response` 用于在流打开时快照 HTTP 状态码与上游头（cf-ray、x-openrouter-provider 等），`flatten_exception_chain` 沿 `__cause__`/`__context__` 最多 4 层展开 OpenAI/httpx 包装异常，`log_stream_retry`/`emit_stream_drop` 将结构化 WARNING 写入 `agent.log` 并通过 `agent._buffer_status`/`_touch_activity` 输出用户可见的紧凑提示。
- `stream_single_writer.py`：对 `AIAgent` 上的 `_claim_stream_writer`/`_stream_writer_is_current` 做 best-effort 封装，返回单调 token 并用 `0` 表示“无围栏”，保证即使方法缺失或抛出也不会导致调用方崩溃。
- `thread_scoped_output.py`：通过 `contextlib.contextmanager` 暴露 `thread_scoped_silence()`，安装一次性的 `_ThreadRoutingStream` 代理到 `sys.stdout`/`sys.stderr`，按 `threading.get_ident()` 维护嵌套深度，将被标记的线程 I/O 重定向到 `os.devnull`，其余线程直通原始流。
依赖方向单向向外：本模块仅依赖标准库与 `logging`，不反向依赖 `run_agent`，从而避免循环导入；所有副作用（日志、全局流代理）都在函数边界内完成。
