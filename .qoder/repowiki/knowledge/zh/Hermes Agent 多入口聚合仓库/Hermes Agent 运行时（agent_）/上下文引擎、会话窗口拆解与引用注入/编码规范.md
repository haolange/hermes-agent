- 上下文引擎通过继承 `ContextEngine` ABC 并以 `name` 属性标识，核心行为由 `should_compress`/`compress`/`update_from_response` 等抽象方法约定，可选能力以带默认 no-op 的方法暴露以便向后兼容。
- 对外部副作用（文件读取、git 子进程、URL 抓取）统一包装为独立函数并在异常时返回 `(warning, None)` 或抛出明确 `ValueError`，由上层聚合为 `ContextReferenceResult.warnings`。
- 路径访问一律先 `resolve()` 再经 `_ensure_reference_path_allowed` 校验，敏感目录/文件使用集中常量列表（`.ssh`、`.aws`、`.hermes/auth.json` 等）并通过 `agent.file_safety.get_read_block_error` 复用单一黑名单源。
- Token 估算统一采用 `chars/4` 近似（`_chars_to_tokens`、`estimate_tokens_rough`），避免精确 tokenizer 开销，使 UI 数字与压缩阈值保持一致。
- UI 渲染与数据计算分离：`compute_*` 函数产出结构化 payload，`render_*` 函数仅负责把 payload 转为 CLI/gateway 所需的文本行，同一 payload 可被多种渲染器复用。
- 对超大注入量采用双阈值策略：超过 context_length 的 25% 发出 warning，超过 50% 直接 `blocked=True` 拒绝注入，保证上下文不会被单条消息撑爆。
