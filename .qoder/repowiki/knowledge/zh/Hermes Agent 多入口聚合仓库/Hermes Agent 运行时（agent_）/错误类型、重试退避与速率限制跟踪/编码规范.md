- 对外暴露的解析函数统一返回 Optional[T]，在缺少必要输入时返回 None 而非抛错（如 `parse_retry_after_seconds`、`parse_rate_limit_headers`）。
- 对不可信外部输入（headers、错误对象属性）一律通过 `_safe_int`/`_safe_float` 或 try/except 包装后再使用，失败时回退到默认值。
- 针对特定供应商的异常形态采用“特征匹配”判定函数（如 `is_zai_coding_overload_error` 组合 status_code/base_url/model/error_text 多字段判断），再交由上层策略分支处理。
- 共享的模块级常量（如 `_ZAI_CODING_OVERLOAD_SHORT_ATTEMPTS`、`_ZAI_CODING_OVERLOAD_LONG_BACKOFF`）集中在文件顶部，供多个相关函数复用以避免参数漂移。
