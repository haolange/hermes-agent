模块由三个职责独立的文件组成：
- `agent/errors.py`：集中定义领域异常类（`SSLConfigurationError`、`EmptyStreamError`、`MoAPresetNotFoundError`），作为上层业务异常的基类。
- `agent/retry_utils.py`：实现通用重试工具，核心是 `jittered_backoff`（基于单调计数器+时间戳的抖动指数退避，避免并发重试风暴）和 `parse_retry_after_seconds`（兼容数值/HTTP-date/headers 映射的 `Retry-After` 解析）。针对 Z.AI Coding Plan GLM-5.2 的 429 过载（code 1305）提供专用路径：`is_zai_coding_overload_error` 识别该特定形状，`adaptive_rate_limit_backoff` 在前 3 次短重试后切换到 30→60→90→120 秒的渐进长退避表，`zai_coding_overload_retry_ceiling` 计算使完整长退避表可触达的重试上限。
- `agent/rate_limit_tracker.py`：解析 Nous Portal/OpenRouter/OpenAI 兼容的 `x-ratelimit-*` 12 个头部，构建 `RateLimitBucket`（limit/remaining/reset/captured_at）与 `RateLimitState`（按 requests/tokens × min/hour 四个窗口组织），并提供 `format_rate_limit_display`（终端富文本进度条+告警）和 `format_rate_limit_compact`（单行状态栏）两种展示格式。
依赖方向单向：上层调用方同时消费这三个模块，模块之间无相互导入。
