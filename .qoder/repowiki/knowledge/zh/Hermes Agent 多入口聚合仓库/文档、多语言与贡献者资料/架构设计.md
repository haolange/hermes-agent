本模块由四个相互独立的子目录组成，各自承担不同职责：
- `docs/`：纯 Markdown/PDF 技术文档，按主题分目录（design、kanban、middleware、observability、plans、security），并包含根级架构/契约类文档（如 session-lifecycle.md、relay-connector-contract.md）。
- `locales/`：YAML 键值型静态消息目录，以 `en.yaml` 为基准源，其他语言文件需保持键完全一致（测试 `tests/agent/test_i18n.py` 强制校验 parity），供 CLI 审批提示与网关斜杠命令回复使用。
- `website/`：基于 Docusaurus 3.10 + React 19 的官方文档站，通过 `docusaurus.config.ts` 配置双语言（en、zh-Hans）、Mermaid 图表、本地搜索与客户端重定向；文档内容位于 `docs/`（含 getting-started、user-guide、developer-guide、guides、integrations、reference 等分类），中文翻译镜像在 `i18n/zh-Hans/...`；构建前通过 `scripts/prebuild.mjs` 及 `extract-automation-blueprints.py`、`generate-skill-docs.py` 等脚本自动生成技能/蓝图页面，侧边栏由 `sidebars.ts` 声明。
- `contributors/emails/`：扁平化存储所有贡献者邮箱文件的只读清单，配合 `README.md` 说明用途。
依赖方向单向：`website/scripts/*` 生成内容写入 `website/docs/reference/skills-*`，不反向依赖源码；`locales/*` 仅被运行时 i18n 模块读取，不被网站引用。
