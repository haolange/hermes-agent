- locales 下每个 YAML 文件使用点号分隔的嵌套键组织消息（如 `gateway.model.switched`），并以 en.yaml 为唯一权威源，新增键必须同步到所有语言文件以保持键集一致。
- website 文档按功能域划分目录（getting-started、user-guide、developer-guide、guides、integrations、reference），每个分类目录内通过 `_category_.json` 定义侧边栏分组标题。
- 网站构建前通过 `prestart`/`prebuild` 钩子调用 `scripts/prebuild.mjs`，再由 Python 脚本（`extract-automation-blueprints.py`、`generate-skill-docs.py`、`generate-llms-txt.py`）动态生成 skills 与 automation blueprints 参考页，避免手工维护大量重复文档。
- Docusaurus 配置集中在 `docusaurus.config.ts`，通过 `plugins` 注册客户端重定向、`themes` 启用 Mermaid 与本地搜索、`i18n` 声明默认 locale 与可用语言，并通过 `overrides` 锁定第三方依赖版本。
- contributor 邮箱以文件名即邮箱地址的扁平结构存放于 `contributors/emails/`，无额外元数据或索引文件，便于 Git 追踪变更历史。
