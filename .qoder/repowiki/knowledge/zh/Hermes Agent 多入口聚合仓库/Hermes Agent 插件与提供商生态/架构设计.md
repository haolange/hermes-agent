本模块以 providers/base.py 中的 ProviderProfile 为跨子模块契约：所有 model-providers/*、image_gen/*、video_gen/*、browser/*、web/* 等插件均以 plugin.yaml 声明 name/aliases/env_vars/base_url/auth_type 等字段，由 plugins/plugin_utils.py 提供的 lazy_singleton/SingletonSlot 保证多进程/多线程下客户端单例安全；各子目录按能力域划分（platforms/ 提供消息通道适配器、model-providers/ 提供推理后端、memory/ 提供记忆存储、cron_providers/ 提供定时任务调度、dashboard_auth/ 提供仪表板认证方式），彼此互不依赖，仅通过统一的 plugin.yaml + __init__.py 暴露 Profile 或工具函数，由上层加载器按需发现并实例化。
