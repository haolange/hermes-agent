- 每个提供商以 `ProviderProfile` 实例形式声明，并在模块顶层调用 `register_provider()` 完成自注册，而非集中维护列表。
- 对可能失败的外部 I/O（如 `fetch_models`、用户插件导入）采用 try/except 捕获并记录 warning/debug 日志，保证 discovery 过程健壮且不影响主流程。
- 通过覆写 `ProviderProfile` 的钩子方法（`prepare_messages`、`build_extra_body`、`build_api_kwargs_extras`、`fetch_models` 等）注入提供商特定行为，避免在共享代码中添加 if-else 分支。
- 使用模块级全局 `_discovered` 标志与 `_PROVIDER_LIST_CACHE` 实现懒加载与结果缓存，确保 discovery 只执行一次且列表查询 O(1)。
- 用户插件通过独立模块名（`_hermes_user_provider_<name>`）动态加载，避免多个 HERMES_HOME 下的同名插件相互别名污染。
