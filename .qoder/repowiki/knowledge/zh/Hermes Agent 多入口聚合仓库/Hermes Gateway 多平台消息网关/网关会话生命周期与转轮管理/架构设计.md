模块按职责拆分为六个协作文件：
- `session.py`：会话入口与持久化模型，定义 `SessionSource`/`SessionContext`/`SessionEntry` 数据类，实现会话键安全校验（防路径穿越）、PII 脱敏、动态系统提示构建、自动续期窗口（`HERMES_AUTO_CONTINUE_FRESHNESS`）以及 `get_or_create_session` 等路由级 API。
- `session_context.py`：基于 `contextvars.ContextVar` 的每任务会话变量存储，替代旧 `os.environ` 以避免 asyncio 并发覆盖；提供 `set_session_vars`/`clear_session_vars`/`reset_session_vars` 及 `get_session_env` 向后兼容桥接，并维护 `_session_context_engaged` 进程级 latch 控制子进程环境泄漏策略。
- `session_state.py`：将 GatewayRunner 中散落的 Dict 属性收敛为三层数据类 `TurnState`/`ConversationState`/`PersistentState`，并通过 `SessionFieldView`/`TurnLeaseTokenView` 等 MutableMapping 适配器暴露 legacy dict 视图以兼容测试与遗留调用点。
- `turn_context.py`：提取 `_run_agent_inner` 的闭包局部变量到 `TurnContext` dataclass，作为 `TurnRunner` 的可注入上下文，使进度回调、语音 ACK、流消费器等从闭包迁移为显式字段。
- `turn_lease.py`：基于 `asyncio.Lock` 的 per-session_id 转轮租约注册表 `SessionTurnLeaseRegistry`，解决多路由键映射同一 session_id 导致的并发转轮交错问题；提供带超时、生成号校验、idempotent release 与 mid-turn rebind（压缩旋转时跟随新 session_id）的安全语义。
- `session_stall.py`：纯策略函数，依据共享活动快照 (`agent.session_activity`) 计算空闲秒数并决定何时发送/清除“会话停滞”通知，不持有状态。
依赖方向单向向外：本模块被 `gateway/run.py`、`gateway/base.py` 等上层编排调用，自身仅依赖 `config`、`whatsapp_identity`、`utils.atomic_replace`、`agent.turn_context`、`agent.session_activity` 等底层能力，不反向依赖网关调度器。
