- 数据类统一提供 `to_dict` / `from_dict` 成对方法用于 JSON 持久化，并在 `from_dict` 中对路径敏感字段执行 `_is_path_unsafe`/`_is_session_key_unsafe` 校验以防目录穿越。
- 会话上下文通过 `contextvars.ContextVar` 集中声明在模块顶层（如 `_SESSION_PLATFORM`、`_SESSION_CHAT_ID` 等），并由 `_VAR_MAP` 统一注册以便批量 reset/clear。
- 对历史 Dict 属性的访问通过 `SessionFieldView`/`TurnLeaseTokenView` 等 `MutableMapping` 适配器暴露，新增字段只需在 `LEGACY_FIELD_SPECS` 中注册而不改动调用方。
- 异步资源采用 token 模式（`TurnLeaseToken`、`scoped_current_session_id` 返回 tokens）配合 idempotent release，确保 stale unwind 不会释放后到的租约或上下文。
- 对外部不可信文本（平台名称、聊天名、用户 ID）统一经 `_format_untrusted_prompt_value`/`neutralize_untrusted_inline_text` 清洗后再拼入系统提示，防止 prompt injection。
- 策略型逻辑（如停滞通知判定）以纯函数形式实现（`should_emit_session_stall_notification`、`resolve_session_idle_seconds_from_activity`），不持有内部状态，便于测试与替换。
