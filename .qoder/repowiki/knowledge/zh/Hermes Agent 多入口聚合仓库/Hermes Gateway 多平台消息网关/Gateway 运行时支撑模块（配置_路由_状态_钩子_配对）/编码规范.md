- 配置项统一使用 `dataclass` + `to_dict` / `from_dict` 成对方法实现可序列化，并在 `from_dict` 中通过 `_coerce_bool` / `_coerce_int` / `_coerce_float` 等工具函数做宽松类型转换，保证 YAML 拼写错误不会导致启动失败。
- 平台相关行为通过集中映射表（如 `_PLATFORM_CONNECTED_CHECKERS`、`PORT_BINDING_PLATFORM_VALUES`、`PLATFORM_TOKEN_ENV_NAMES`）而非 if/elif 链进行分派，新增平台只需添加条目即可接入。
- 对外部资源（平台适配器、状态数据库、psutil 等）采用延迟 import 或 try/except ImportError 包裹，使轻量 CLI 路径（如 `hermes chat`）无需安装全部 SDK 也能运行。
- 持久化写入一律先写临时文件再原子替换（`atomic_replace` / `os.replace`），并对敏感文件（配对数据）显式 `chmod 0o600`，保证并发读写安全与权限最小化。
- 进程级互斥通过文件锁实现：POSIX 用 `fcntl.flock`，Windows 用 `msvcrt.locking` 偏移量锁，配合 `_try_acquire_file_lock` / `_release_file_lock` 封装，避免重复启动。
- 钩子系统采用“发现 + 动态加载”模式：扫描目录读取 `HOOK.yaml` 元数据后 `importlib.util.spec_from_file_location` 加载 `handler.py`，并以 `sys.modules` 注入模块名以解决 Pydantic/typing 前向引用问题。
