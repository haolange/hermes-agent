- 跨线程通信统一采用 `queue.Queue` 配合 sentinel 对象（`_DONE`/`_FLUSH`/`_ABORT`/`_NEW_SEGMENT`/`_COMMENTARY`）进行无锁排队，避免阻塞 agent 工作线程。
- 事件模型全部使用 `@dataclass(frozen=True)` 定义不可变数据类，并通过显式 `Union[...]` 枚举所有合法事件类型，使缺失 case 在类型检查阶段暴露。
- 平台适配通过注入的 adapter 对象解耦：dispatcher 调用 `render_message_event`/`format_tool_event`，consumer 调用 `adapter.edit_message`/`send_draft`，tts consumer 调用 `begin_streaming_tts`/`write_streaming_tts`/`abort_streaming_tts`，具体渲染细节完全下沉到各平台适配器。
- 异步任务对异常一律捕获并记录 debug 日志后继续，确保 presentation 层错误不会中断 agent 主循环或 TTS 会话。
- 长生命周期状态（如 `_last_tool`、`_draft_id_counter`、`_preview_message_ids`、`_delivered_segment_texts`）在 segment break 或工具边界处通过专用 reset 方法清理，保证多段回复的隔离性。
- 可选能力通过运行时探测（`supports_draft_streaming`、`supports_streaming_tts`、`REQUIRES_EDIT_FINALIZE`）而非编译期分支启用，失败时自动降级到 edit 或 whole-file 回退路径。
