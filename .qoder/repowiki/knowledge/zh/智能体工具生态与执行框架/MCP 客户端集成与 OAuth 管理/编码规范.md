- 所有 MCP 工具名称在注册到全局注册表时，必须遵循 `mcp_{sanitized_server}_{sanitized_tool}` 的命名规范，其中特殊字符被转换为下划线。
- 在将 MCP 工具的错误信息或描述返回给 LLM 之前，必须通过 `_sanitize_error` 函数执行正则匹配，以剥离潜在的凭证信息（如 API Key、Bearer Token）。
- 针对 stdio 类型的 MCP 子进程，其 stderr 输出必须统一重定向至共享日志文件 (`~/.hermes/logs/mcp-stderr.log`)，以防止污染终端用户界面 (TUI)。
- 在处理 MCP 服务器的输入 Schema 时，必须通过 `_normalize_mcp_input_schema` 进行标准化，包括将 `definitions` 转换为 `$defs` 以及修剪无效的 `required` 字段。
