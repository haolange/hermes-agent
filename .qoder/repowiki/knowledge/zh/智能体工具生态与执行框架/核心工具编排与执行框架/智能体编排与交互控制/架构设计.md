- **委派架构**：`delegate_tool.py` 实现基于 `ThreadPoolExecutor` 的并发子智能体生成，通过 `_active_subagents` 注册表管理生命周期，支持 `leaf`（叶子）与 `orchestrator`（协调者）角色分层及深度限制。
- **交互原语**：`clarify_tool.py` 定义交互接口，`clarify_gateway.py` 利用线程安全的 `_ClarifyEntry` 队列在网关模式下实现阻塞式用户问答；`slash_confirm.py` 处理斜杠命令的异步确认流程。
- **安全审批**：`approval.py` 作为危险命令检测的中心，维护基于 `contextvars` 的会话状态，集成硬线阻断（Hardline Blocklist）与模式匹配，并提供 CLI 同步提示与网关异步回调双路径。
- **工具发现**：`tool_search.py` 实现渐进式工具披露机制，通过 BM25 算法构建延迟加载目录，动态替换模型可见的工具集以优化上下文窗口占用。
- **高级推理**：`mixture_of_agents_tool.py` 采用两层架构，并行调用多个参考模型生成响应，再由聚合模型合成最终结果，依赖 OpenRouter API 进行复杂任务处理。
