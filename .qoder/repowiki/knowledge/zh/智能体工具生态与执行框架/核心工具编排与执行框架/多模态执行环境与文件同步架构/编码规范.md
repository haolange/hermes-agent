- 所有非本地绑定挂载的后端均在初始化时注入 `FileSyncManager`，并在 `_before_execute` 钩子中触发限流同步，在 `cleanup` 中执行反向同步。
- 云端及 SSH 后端通过向 stdout 注入带 Session ID 的唯一标记（如 `__HERMES_CWD_{id}__`）来解析并持久化工作目录状态。
- 批量文件传输采用 Tar 流式管道（SSH/Modal）或 SDK 批量接口（Daytona），以避免单文件传输带来的高频网络往返开销。
- 执行环境在销毁前均尝试保存文件系统快照（如 Modal 的 `snapshot_filesystem` 或 Singularity 的 overlay 路径映射），以支持跨会话的状态恢复。
