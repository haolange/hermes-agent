- **并发与上下文层**：`thread_context.py` 封装 `contextvars` 与回调快照，解决工作线程中审批/安全上下文丢失问题；`interrupt.py` 实现基于线程 ID 的中断信号机制，支持细粒度的会话级中断。
- **状态持久化层**：`checkpoint_manager.py` 构建基于共享 Git 裸仓库的文件系统快照引擎，通过 per-project refs 和 indexes 实现跨项目去重与快速回滚；`memory_tool.py` 提供基于文件锁和原子写入的双存储（MEMORY.md/USER.md）持久化记忆，支持注入前的威胁模式扫描。
- **进程管理层**：`process_registry.py` 维护内存中的后台进程注册表，通过读写器线程（PTY/Popen/Env Poller）捕获输出，并提供 JSON 检查点以实现网关重启后的进程恢复与看门狗心跳同步。
- **业务工具层**：`todo_tool.py` 和 `kanban_tools.py` 分别提供会话内任务列表与分布式看板工作流支持，后者通过环境变量 gating 区分 Worker 与 Orchestrator 权限，并直接操作 SQLite 数据库进行任务生命周期管理。
- **辅助设施**：`session_search_tool.py` 基于 FTS5 索引实现跨会话历史检索；`debug_helpers.py` 提供通用的工具调用调试日志记录框架。
