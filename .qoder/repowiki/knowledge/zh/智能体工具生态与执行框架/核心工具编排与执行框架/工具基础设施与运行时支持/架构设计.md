- **核心注册中心**：`tools/registry.py` 定义了 `ToolRegistry` 单例，采用模块级自注册模式（AST 扫描 + 动态导入），通过 TTL 缓存优化可用性检查，并提供统一的工具分发与 Schema 生成接口。
- **依赖与环境管理**：`tools/lazy_deps.py` 实现了基于白名单的 venv  scoped 懒加载安装机制；`tools/env_probe.py` 和 `tools/env_passthrough.py` 分别负责本地 Python 工具链状态探测及沙箱环境变量安全透传（含 Hermes 凭证拦截）。
- **后端选择辅助**：`tools/tool_backend_helpers.py` 与 `tools/managed_tool_gateway.py` 封装了 Nous Tool Gateway 的认证逻辑及 Modal/Direct 后端的自动切换策略，为具体工具提供统一的配置解析入口。
