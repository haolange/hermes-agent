- **中央注册机制**：采用 `tools/registry.py` 作为核心枢纽，各子模块（如浏览器、文件、MCP）在导入时通过 `registry.register()` 自动完成元数据与处理器的自注册。
- **动态可用性探测**：内置带 TTL 的缓存检查器 (`check_fn`)，实时评估 Docker、Modal 或 API 密钥等外部依赖状态，确保仅向模型暴露当前可用的工具集。
- **统一调度网关**：提供 `dispatch` 接口实现异步桥接与异常标准化，并通过 `managed_tool_gateway` 抽象层统一处理 Nous 等云端厂商的 OAuth 鉴权与路由转发。
- **隔离与扩展**：支持基于 `override` 标志的工具替换机制，允许插件或 MCP 服务器在不破坏核心逻辑的前提下动态注入或覆盖原生工具实现。
