- 所有公开的工具函数（如 `read_file_tool`）均返回 JSON 格式的字符串，成功时包含结果数据，失败时包含 `error` 字段，以确保 LLM 能够统一解析工具调用结果。
- 在执行写操作（`write_file` 或 `patch`）前，必须通过 `_check_sensitive_path` 和 `_check_cross_profile_path` 进行安全校验，阻止对系统关键文件或跨 Hermes 配置文件的未授权修改。
- 文件读取操作内置防循环机制，通过 `_read_tracker` 记录连续相同的读取请求，当检测到 Agent 陷入重复读取死循环时（通常超过 3-4 次），返回阻断错误并提示 Agent 停止重试。
- 写操作采用原子化策略，通过 `_atomic_write` 先将内容写入同目录下的临时文件，再使用 `mv` 命令替换原文件，确保在写入中断或崩溃时不会损坏原始文件内容。
