- **入口层 (`file_tools.py`)**：定义 `read_file_tool`, `write_file_tool`, `patch_tool`, `search_tool` 等核心工具函数，负责参数校验、路径解析（基于 `TERMINAL_CWD`）、敏感路径拦截（如 `/etc/`）以及防循环读取的计数器逻辑。
- **操作实现层 (`file_operations.py`)**：通过抽象基类 `FileOperations` 及其实现 `ShellFileOperations`，将文件操作转化为可在不同终端环境（本地、Docker、SSH 等）中执行的 Shell 命令。支持原子写入、模糊匹配补丁（V4A 格式）以及基于 ripgrep/grep 的内容搜索。
- **状态协调层 (`file_state.py`)**：提供进程级的 `FileStateRegistry`，用于跟踪多 Agent 或子任务对同一文件的读写时间戳与锁状态，防止并发编辑导致的数据覆盖或陈旧写入。
- **依赖方向**：工具入口依赖操作实现层执行具体 I/O，并在写操作前后调用状态协调层进行一致性检查；所有模块均通过 `_get_file_ops` 动态获取与当前任务绑定的终端环境实例。
