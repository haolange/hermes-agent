- **入口层**：包含 `install.sh` (Linux/macOS/Android) 和 `install.ps1` (Windows) 作为核心引导脚本，负责环境探测、依赖管理（uv, Node.js, Git）及虚拟环境构建。
- **应用桥接层**：`whatsapp-bridge/` 子模块基于 Express 和 Baileys 库实现独立的 Node.js 服务，通过 HTTP API 与 Python 网关交互，处理消息收发、媒体缓存及会话状态。
- **运维与发布层**：`release.py` 负责基于 CalVer 的 Changelog 生成与 GitHub 发布；`run_tests.sh` 封装了隔离的并行测试执行逻辑。
- **共享库**：`lib/node-bootstrap.sh` 提供可复用的 Node.js 版本管理与安装逻辑，被主安装脚本引用。
