- **Categorical Organization**: Skills are grouped into semantic domains (e.g., `creative`, `mlops`, `research`) with `DESCRIPTION.md` files defining scope.
- **Standardized Skill Interface**: Each skill is a self-contained directory featuring a `SKILL.md` manifest (metadata, instructions) and optional `references/`, `scripts/`, and `templates/` subdirectories.
- **Embedded Tooling**: Complex skills (e.g., `comfyui`, `research-paper-writing`) include Python scripts and shell utilities for environment setup, dependency checking, and execution, treating the skill as a mini-application.
- **Documentation-Driven Execution**: Agents rely on structured Markdown guides (`SKILL.md`) and reference docs to orchestrate tasks, with scripts serving as executable extensions of the skill's logic.
