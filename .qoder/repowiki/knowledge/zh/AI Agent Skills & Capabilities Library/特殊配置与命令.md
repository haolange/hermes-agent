- **ComfyUI Setup**: `bash scripts/comfyui_setup.sh` performs hardware checks, installs `comfy-cli`, and launches the server.
- **Hardware Verification**: `python3 scripts/hardware_check.py` detects GPU/VRAM capabilities to recommend local vs. cloud execution.
- **Dependency Checking**: `python3 scripts/check_deps.py` validates workflow dependencies against a running ComfyUI instance.
