- **统一配置与状态桥接**：`hermes_cli/config.py` 与 `hermes_constants.py` 定义了全局配置加载逻辑，`gateway/run.py` 在启动时将 `config.yaml` 的关键设置（如终端、代理、安全策略）桥接为环境变量，确保长运行进程与短时 CLI 命令行为一致。
- **跨模块状态持久化**：`hermes_state.py` 提供基于 SQLite (WAL模式) 的会话存储，被 CLI (`hermes_cli/main.py`)、网关 (`gateway/run.py`) 和 Web 服务器 (`hermes_cli/web_server.py`) 共同依赖，实现多入口下的会话历史同步与全文检索。
- **插件与钩子扩展机制**：`hermes_cli/plugins.py` 定义了统一的插件注册表与生命周期钩子（如 `pre_tool_call`, `pre_gateway_dispatch`），允许外部模块在不修改核心代码的情况下介入 CLI 命令执行、网关消息分发及工具调用流程。
- **集中式日志与会话上下文**：`hermes_logging.py` 提供线程安全的会话上下文注入（Session Tag），确保来自 CLI、网关或后台任务的日志均能关联到特定会话 ID，并统一输出至 `~/.hermes/logs/` 目录。
