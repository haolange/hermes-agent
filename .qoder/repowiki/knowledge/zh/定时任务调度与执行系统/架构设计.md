- **分层架构**：模块分为数据存储层 (`jobs.py`) 和调度执行层 (`scheduler.py`)，通过 `__init__.py` 暴露统一的 CRUD 接口 (`create_job`, `tick` 等)。
- **存储机制**：采用 JSON 文件 (`~/.hermes/cron/jobs.json`) 持久化任务状态，配合 `threading.Lock` 和原子替换 (`atomic_replace`) 确保并发读写安全。
- **调度逻辑**：`tick()` 函数作为核心入口，通过文件锁防止多进程重复执行；支持并行线程池处理普通任务，串行线程池处理涉及环境变量或工作目录变更的任务。
- **执行隔离**：任务在独立的 Agent 会话中运行，支持加载特定技能 (Skills)、脚本预处理 (`no_agent` 模式) 以及动态配置文件重载，确保执行环境互不干扰。
