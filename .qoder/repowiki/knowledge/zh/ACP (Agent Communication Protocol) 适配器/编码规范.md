- 跨线程通信统一使用 `agent.async_utils.safe_schedule_threadsafe` 将协程调度到主事件循环，避免直接在 worker 线程操作 asyncio 对象。
- 所有面向用户的文本输出（如工具结果、资源内容）均经过 `_truncate_text` 或类似逻辑进行长度限制，防止大体积数据阻塞 ACP UI。
- 文件路径处理遵循 WSL 兼容性原则，在 `session.py` 和 `server.py` 中通过 `_translate_acp_cwd` 和 `_path_from_file_uri` 自动转换 Windows 驱动器路径。
- 工具调用元数据（ID、参数、快照）通过 `tool_call_ids` 队列和 `tool_call_meta` 字典在 `events.py` 中进行有状态追踪，以确保开始与完成事件的精确匹配。
