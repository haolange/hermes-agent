- **入口层**：`entry.py` 负责 CLI 启动、环境变量加载（`~/.hermes/.env`）及日志配置（stderr 输出以隔离 stdout 的 JSON-RPC 传输）。
- **核心服务层**：`server.py` 实现 `HermesACPAgent`，继承自 `acp.Agent`，处理 ACP 生命周期（初始化、认证、会话增删改查）及消息流转换。
- **状态管理层**：`session.py` 提供 `SessionManager`，通过 `SessionDB` 持久化会话历史，并负责 `AIAgent` 实例的工厂化创建与上下文恢复。
- **协议桥接层**：`events.py` 和 `tools.py` 负责将 Hermes 内部事件（思考、工具进度）映射为 ACP 标准更新（`AgentThoughtChunk`, `ToolCallStart` 等）。
- **安全与权限层**：`auth.py` 处理运行时凭证检测；`permissions.py` 和 `edit_approval.py` 通过 ContextVar 绑定异步权限请求，实现危险命令与文件编辑的同步审批桥接。
