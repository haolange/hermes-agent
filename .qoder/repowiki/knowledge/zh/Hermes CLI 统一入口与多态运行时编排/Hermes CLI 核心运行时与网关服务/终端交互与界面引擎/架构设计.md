- **UI 渲染层**：`curses_ui.py` 封装了通用的 Curses 事件循环（`_run_curses_menu`），支持模糊搜索、键盘导航及非 TTY 环境的文本回退，为多选/单选组件提供底层支持。
- **主题配置层**：`skin_engine.py` 实现了基于 YAML 的数据驱动皮肤系统，通过 `SkinConfig` 管理颜色、品牌文案及 Spinner 动画，并提供 `prompt_toolkit` 样式映射接口以实现运行时换肤。
- **输入增强层**：`pt_input_extras.py` 通过注入 `prompt_toolkit` 的 ANSI 序列映射表，解决 Kitty/xterm 等现代终端中 Shift/Ctrl+Enter 及焦点事件的兼容性问题。
- **外部交互层**：`clipboard.py` 和 `browser_connect.py` 分别负责跨平台（macOS/Windows/Linux/WSL2）的剪贴板图像提取与 Chromium CDP 调试端口连接；`pty_bridge.py` 则封装 `ptyprocess` 为 Web 仪表板提供 POSIX 伪终端桥接。
- **状态与记忆层**：`voice.py` 管理录音/TTS 的状态机与线程同步；`memory_setup.py` 结合 Curses UI 与插件系统，引导用户完成记忆提供商的配置。
