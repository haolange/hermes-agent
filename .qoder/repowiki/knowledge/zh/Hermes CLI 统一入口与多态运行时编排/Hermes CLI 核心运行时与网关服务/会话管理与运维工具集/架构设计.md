- **入口路由**：由 `hermes_cli/main.py` 统一解析 CLI 子命令，并动态分发给各功能模块（如 `claw_command`, `cron_command`）。
- **功能分层**：
  - **迁移与清理**：`claw.py` 负责从 OpenClaw 迁移配置，`migrate.py` 处理特定模型退役迁移，`checkpoints.py` 管理文件系统快照。
  - **数据持久化**：`backup.py` 实现全量/增量 ZIP 备份与 SQLite 安全拷贝，`goals.py` 基于 SessionDB 实现跨会话的持久化目标状态机。
  - **自动化与策展**：`cron.py` 封装定时任务调度逻辑，`curator.py` 管理技能的自动归档、 pinned 状态及生命周期。
  - **诊断与洞察**：`dump.py` 生成环境摘要，`prompt_size.py` 计算提示词体积，`session_recap.py` 提供会话活动回顾。
- **依赖方向**：所有模块均依赖底层配置系统 (`hermes_cli.config`) 和状态数据库 (`hermes_state.SessionDB`)，部分模块（如 `goals.py`）通过辅助客户端 (`agent.auxiliary_client`) 调用 LLM 进行状态判定。
