- **独立命令模块**：`oneshot.py`、`send_cmd.py` 和 `fallback_cmd.py` 实现了低耦合的 CLI 子命令，通过局部导入（lazy imports）避免影响主 CLI 启动速度。
- **服务抽象层**：`gateway.py` 封装了跨平台的服务管理逻辑，根据操作系统自动选择 systemd（Linux）、launchd（macOS）或手动进程管理，并处理权限提升（sudo）和环境桥接。
- **配置与状态同步**：模块深度集成 `hermes_cli.config` 和 `hermes_state`，在一次性模式中手动初始化会话数据库，并在服务安装时动态生成包含虚拟环境路径和用户环境的单元文件。
