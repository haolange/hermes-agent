- Early bootstrap functions in `main.py` (e.g., `_apply_profile_override`, `_suppress_mouse_residue_early`) execute before major imports to ensure environment variables and terminal states are correctly set for subsequent modules.
- Configuration loading functions (`load_config`, `read_raw_config`) use module-level caches keyed by file path and mtime_ns to avoid redundant YAML parsing and merging on repeated calls.
- Interactive prompts in `callbacks.py` use `queue.Queue` and `time.monotonic()` to bridge synchronous agent logic with the asynchronous prompt_toolkit event loop, ensuring timeouts are handled correctly without blocking the UI thread.
- Environment variable loading sanitizes credential values (ending in `_API_KEY`, `_TOKEN`, etc.) by stripping non-ASCII characters to prevent HTTP header encoding errors, logging warnings for any modifications.
