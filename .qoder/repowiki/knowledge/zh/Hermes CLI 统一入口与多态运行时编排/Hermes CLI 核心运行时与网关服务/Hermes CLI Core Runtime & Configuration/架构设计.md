- **Entry Point & Bootstrapping**: `main.py` serves as the primary executable, implementing early-stage bootstrapping (UTF-8 stdio setup, process title setting, profile resolution, and mouse-residue suppression) before importing heavy dependencies.
- **Argument Parsing**: `_parser.py` isolates the `argparse` tree construction, allowing external tools (like `relaunch.py`) to introspect flags without executing the main logic. It defines top-level and `chat` subcommands, while other subcommands are registered inline in `main.py`.
- **Configuration Management**: `config.py` handles the loading, merging, and saving of `config.yaml` and `.env` files. It implements a thread-safe caching mechanism (`_CONFIG_LOCK`) and supports managed modes (NixOS, Homebrew) and container-aware permission handling.
- **Environment Loading**: `env_loader.py` manages the loading of `.env` files with fallback logic, sanitizes non-ASCII characters from credentials, and integrates with external secret sources like Bitwarden Secrets Manager.
- **Interactive Runtime**: `callbacks.py` bridges TUI event loops with agent prompts (clarification, approvals, secrets), using `queue.Queue` for synchronous blocking within the async UI context.
- **Extensibility & Hooks**: `hooks.py` and `middleware.py` provide interfaces for shell-script hooks and request/response middleware, allowing plugins to intercept and modify tool/LLM execution flows.
- **Output & Completion**: `cli_output.py` standardizes colored console output, while `completion.py` dynamically generates shell completion scripts (bash, zsh, fish) by walking the live argparse parser tree.
