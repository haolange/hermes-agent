- **Configuration**: Uses `pyyaml` for parsing `config.yaml` and `python-dotenv` for `.env` loading, with custom atomic write utilities (`utils.atomic_replace`) to prevent corruption.
- **Secrets Management**: Integrates with Bitwarden Secrets Manager via `agent.secret_sources.bitwarden` for external credential injection.
- **Shell Integration**: Generates dynamic shell completion scripts by introspecting `argparse._SubParsersAction` choices, avoiding hardcoded command lists.
