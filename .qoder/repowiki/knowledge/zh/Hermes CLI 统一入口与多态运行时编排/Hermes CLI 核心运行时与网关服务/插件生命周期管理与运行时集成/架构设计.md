- **双层架构**：`plugins_cmd.py` 处理CLI交互（Git克隆、环境配置、TUI切换），`plugins.py` 实现核心运行时逻辑（清单解析、模块导入、单例管理）。
- **多源发现机制**：按优先级扫描 Bundled（仓库内置）、User（`~/.hermes/plugins`）、Project（`.hermes/plugins`）及 Pip Entry-points，支持用户插件覆盖内置插件。
- **沙箱化加载**：通过 `importlib.util` 将目录插件动态导入 `hermes_plugins` 命名空间，执行 `register(ctx)` 完成工具、钩子及中间件的注册。
- **分类路由**：根据 `plugin.yaml` 中的 `kind` 字段（如 `exclusive`, `model-provider`）将插件分流至专用子系统（如 Memory 或 Providers），其余由通用管理器处理。
