- **数据模型层**：在 `mcp_catalog.py` 中定义 `CatalogEntry`、`TransportSpec`、`AuthSpec` 等数据类，映射 `optional-mcps/` 下的 `manifest.yaml` 结构。
- **解析与验证层**：`_parse_manifest` 负责读取并校验 YAML 文件，确保版本兼容性及字段完整性，通过 `list_catalog` 暴露可用条目。
- **安装执行层**：`install_entry` 编排完整流程，包括 Git 克隆（支持 SHA/分支）、环境变量交互提示（存入 `.env`）、以及将配置写入 `config.yaml`。
- **工具发现与过滤**：集成 `_probe_tools` 动态获取服务器能力，并通过 `curses_checklist` 提供交互式工具启用界面，支持持久化 `tools.include` 过滤规则。
- **依赖边界**：依赖 `hermes_cli.config` 进行状态持久化，依赖 `hermes_cli.mcp_config` 进行底层连接探测，依赖 `hermes_cli.curses_ui` 提供终端交互。
