- **入口层**：`main.py` 作为主入口，执行早期的环境探测（如 Termux 优化、TTY 检查）和配置预加载（Profile 切换、.env 注入）。
- **解析层**：`_parser.py` 独立维护 `argparse` 定义，支持模块内省和命令重启时的参数继承。
- **业务逻辑层**：`commands.py` 集中管理斜杠命令注册表（Slash Commands），为 CLI、网关及第三方平台（Telegram/Discord）提供统一的命令元数据。
- **服务层**：`gateway.py` 处理后台服务的生命周期管理（安装、启停、状态监控），支持 systemd/launchd 集成。
- **表现层**：`web_server.py` 基于 FastAPI 构建 Web UI 后端，提供 REST API 和 WebSocket 实时通信能力。
- **认证层**：`auth.py` 实现多提供商（OAuth/API Key）的统一认证管理与凭证持久化。
