- 所有 OAuth 令牌刷新逻辑均包含 `ACCESS_TOKEN_REFRESH_SKEW_SECONDS` 偏置量，在令牌实际过期前预留时间窗口进行预刷新。
- 敏感凭证在日志记录或追踪时，必须通过 `_token_fingerprint` 函数转换为 SHA256 短哈希，严禁明文输出。
- 针对 API Key 提供商，统一采用“环境变量优先、.env 文件次之、凭证池兜底”的三级查找策略 (`_resolve_api_key_provider_secret`)。
- 所有涉及 `auth.json` 写操作的方法必须包裹在 `_auth_store_lock` 上下文管理器中，以保证文件原子性与并发安全。
