- **核心服务层**：`web_server.py` 作为入口，构建 FastAPI 应用并挂载静态资源，通过中间件链（Host 头校验、OAuth 认证网关、会话令牌校验）保障安全。
- **认证子系统**：`dashboard_auth` 包实现插件化认证架构，定义 `DashboardAuthProvider` 抽象基类与注册中心，支持 Nous Portal 等多身份提供商；`middleware.py` 实现基于 Cookie 的会话验证、自动刷新及路由级访问控制。
- **配置与注册模块**：`dashboard_register.py` 封装 OAuth 客户端自动化注册流程，处理与 Portal 的交互及本地 `.env` 文件的幂等写入。
- **Webhook 管理模块**：`webhook.py` 提供 CLI 命令支持，管理持久化至 JSON 的动态 Webhook 订阅，支持 HMAC 签名验证与事件路由。
